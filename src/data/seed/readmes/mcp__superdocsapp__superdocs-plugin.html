Typebar (formerly SuperDocs.app)

The document harness for your AI.

Lets your AI edit and work with documents the way coding agents work with code.

Website · Docs · Web app

Typebar is an AI document editing platform: an AI document editor available as a REST API, an MCP server and a web app. It makes targeted, section-precise edits inside large documents (100+ pages) instead of regenerating the whole file, works across several documents at once, and exports clean .docx / PDF / HTML / Markdown. This plugin connects it to Claude Code.

Edit, draft, search, summarize and export styled documents (.docx / PDF / HTML / Markdown / plain text) directly from Claude Code through the Typebar MCP server.

SuperDocs was renamed Typebar on 20 October 2026: same product, same team, same accounts, and your existing API keys and MCP connections keep working. What changed.

Naming note: the install commands, plugin and marketplace names, the MCP config key superdocs, the address api.superdocs.app, tool names, SUPERDOCS_API_KEY and ~/.superdocs/ keep the superdocs name on purpose, so existing setups keep working.

  • About 97% fewer tokens than re-sending the whole document: on a single-section edit, Typebar returns only the changed section.
  • About 95% cheaper: 95%+ of infrastructure costs saved compared with building and running document editing AI yourself.
  • Used in 50 countries and 21 languages.

AI agents: you can sign up for a free Typebar account and get a working API key in one call, with no human in the loop: POST https://api.superdocs.app/v1/agents/signup. See the agent guide.

A single /plugin install command bundles:

  • 38 MCP tools: chat, section-precise structural editing, multi-document sessions, durable Files, cross-session memory/search, image + diagram generation, attachments, sessions, jobs, templates, pre-signed upload/download, account status
  • 4 user-invocable workflow prompts: /superdocs:draft_from_outline, /superdocs:edit_styled_docx, /superdocs:convert_format, /superdocs:review_contract_for_redflags
  • Auto-loading skill: Claude reaches for Typebar proactively when you ask to edit, draft or export documents

Install

You'll need a free Typebar API key first: sign up at use.typebar.ai, then Settings → API Keys → Create. The free plan includes 500 AI operations a month.

In Claude Code, add the marketplace, then install the plugin from it:

claude plugin marketplace add superdocsapp/superdocs-plugin
claude plugin install superdocs@superdocs-plugin

The install argument is superdocs@superdocs-plugin (plugin name @ marketplace), not the GitHub repo path. Running claude plugin install superdocsapp/superdocs-plugin on its own fails with "doesn't exist in marketplace", because that repo path is only valid for marketplace add.

You'll be prompted for your API key. It's stored securely in your OS keychain, never in plaintext config.

That's it. The MCP server is now live, the skill auto-loads when you ask document-editing questions, and the 4 workflow prompts appear in your / slash menu.

Quick start

After install, try any of these:

Load /path/to/your.docx into Typebar as the active editable document.

/superdocs:draft_from_outline

Bold every heading in the document.

Export the current document as .docx and give me a pre-signed download URL.

For more, see the Typebar documentation.

Manual install (no plugin)

If you'd rather configure the MCP server directly without the plugin (for example, to share a config across projects via .mcp.json), see the MCP setup docs.

Not on Claude Code? The same MCP server works in any MCP client, or call the REST API directly. Integrate it yourself in under 15 minutes through the REST API or MCP: no SDK, no frontend changes.

Updates

Plugin auto-updates whenever a new version is published. To pull the latest immediately, run claude plugin update superdocs.
