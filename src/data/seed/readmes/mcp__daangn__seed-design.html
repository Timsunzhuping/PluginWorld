SEED Design System

SEED는 당근 제품을 위한 통합된 디자인 언어입니다. 하나의 토큰 소스에서 React, iOS, Android, Lynx까지 여러 플랫폼에 일관된 디자인을 전달하고, Figma와 연동됩니다.

문서 사이트

패키지

Definitions — 토큰·레시피 소스

  • @seed-design/rootage-artifacts — 디자인 토큰·컴포넌트 스키마 정의
  • @seed-design/qvism-preset — 스타일 레시피 정의

Base Libraries — 스타일 생성물

  • @seed-design/css — 디자인 토큰·컴포넌트 스타일·테마 CSS

React

  • @seed-design/react — 스타일드 React 컴포넌트

Lynx

  • @seed-design/lynx-react — Lynx 컴포넌트
