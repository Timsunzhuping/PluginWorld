中文

Win顺 是 Windows 上免费开源的快速搜索启动器：连按两下 Ctrl 弹出搜索框，边打字边出结果。按文件名或拼音秒找文件，搜 Word、Excel、PDF 里的文字，打开应用和系统设置，还有剪贴板历史、对话框搜索、任务栏搜索框、插件和给 AI 用的 MCP 搜索。

它直接读 NTFS 主文件表（MFT）建索引，三百多万个文件几秒建好，增删改名实时跟上，不用装 Everything。不需要账号，不上传数据。界面有简体中文和英文。

📖 每个功能怎么用，见 使用说明。

功能

🔍 文件搜索

  • 双击 Ctrl 打开，再按一次或 Esc 关闭；三百多万个文件里搜一次只要几毫秒。
  • 拼音和首字母：ndbg → 年度报告，baog → 报告；多音字按常用读音。打错了同音字（年度报高）找不到时，自动按读音再找一遍。
  • 搜整台电脑：所有本地磁盘，U 盘可选（没收录的 U 盘插着时，列表末尾会提示你顺手搜一下它）；NAS、内网共享文件夹（SMB） 也能加进来一起搜，服务器关机时收录过的照样能搜到。
  • 排序懂你：自己的文件在前，系统目录、node_modules 在后，名字完全一样的最前。每行显示修改日期，Ctrl+S 在最匹配、最新、最早之间切换。不输入时列出最近打开或最近修改的文件，也可以不列；还可以设成每次打开时清空搜索。
  • 程序优先：搜 curl，curl.exe 排在文件夹 curl 和 curl.h 前面；优先哪些类型可以自己改（默认 exe、bat、cmd、ps1、msi，像 Listary 的“优先显示的文件类型”）。
  • 数字键直达：Ctrl+1～Ctrl+9 打开第几行（也可改成 Alt）；按住 Ctrl 时图标上显示序号，也可以设成一直显示或不显示。
  • 按类型找：选中 文件 后，下面一排是文件夹、文档、图片、视频、压缩包等类型，Ctrl+Tab 依次切换；点 + 或在设置里自己加类型。
  • 搜索面板：结果太多时，点搜索框右上角的小按钮或按 Ctrl+E，同一个窗口展开成面板（像 Listary）：左边按范围、类型、修改时间、大小、位置筛选，右边名称 / 路径 / 大小 / 修改时间四列，点列头排序；什么都不输入也能按条件浏览整个索引（三百万个文件也是毫秒级）。size:>10mb、dm:7d 这类写法直接打在搜索框里也行。再按一次就缩回搜索框。
  • 长文件名：名字放不下时在中间缩短，扩展名和结尾留着（“…第二版.xlsx”）；鼠标停在这一行上，显示完整的名字、位置、大小、修改和创建时间。拖动搜索框的左边或右边可以调宽（记住宽度，双击边缘恢复默认）。
  • 钉住：按 Ctrl+T 或点搜索框右上角的图钉，点别处、打开文件后搜索框都不收起，Esc 关闭；按住左边的放大镜拖动窗口，单击它打开设置。
  • 预览：在结果上按 Alt+P（或右键“预览”）看一眼文件，启动器不关：图片、文本（自动认 UTF-8 / GBK）、Word / Excel / PowerPoint / PDF（用资源管理器预览窗格的同一套预览程序）、文件夹里有什么；上下键换一行就换一个文件，再按 Alt+P 或 Esc 关掉。后台开着 QuickLook 或 Seer 时交给它们。
  • 缩略图：图片、视频、PDF 等在结果里直接显示缩略图，代替类型图标，“打开”“另存为”对话框旁的搜索框里也一样；设置 › 结果列表里可以关。
  • 右键菜单：右键一行有打开位置、复制路径、加入收藏等；按住 Shift 右键（或菜单里的“更多选项”），出现 Windows 自己的完整右键菜单，和资源管理器里一样，选中几行也行；复制、剪切、删除之后搜索框不关。
  • 拖出去就能用：结果直接拖进微信、邮件、资源管理器。
  • 实时更新：读 USN 变更日志，改名、新建、删除马上搜得到；拔 U 盘不会提示“设备正在使用”。

📄 文件内容全文搜索

  • 切到 内容 范围，搜文件里的文字，结果显示命中的那一行。
  • 能搜的文件：
    • 纯文本：txt、md、log、csv、json、代码等；
    • 文档：Word、Excel、PowerPoint、PDF、WPS，结果里显示第几页、第几张幻灯片或哪个表的第几行。
  • 怎么找：可以写多个词、用引号找整个短语，结果按相关度排。
  • 只搜某个文件夹：词后面加文件夹名和斜杠，年度报告 abc/ 只在叫 abc 的文件夹里找（/abc 放在最后也行，工作/abc/ 只要“工作”里的那个）；同名的文件夹都搜，搜索框下面列出它们，Ctrl+Tab 挑其中一个。也可以点下面的收藏文件夹，或在结果的文件夹上右键“在此文件夹中搜内容”。
  • 编码和速度：自动识别 UTF-8、UTF-16、GBK 编码；有内容索引，几十万个文件也很快。第一次建内容索引时，索引服务直接从磁盘读文本文件，杀毒软件不用一个个检查，快得多。超过大小上限的、系统目录里的、类型没列出的文件默认不搜，搜完会告诉你各有几个，点一下就临时把它们也搜了。
  • 安全：文档由一个权限受限的独立进程读取。

🚀 应用和系统设置

  • 应用：开始菜单里的所有应用都能搜，含 Microsoft Store 应用。名称、拼音、首字母（vsc）、程序名（winword）都行；Ctrl+Shift+Enter 以管理员身份运行。
  • 系统设置：约 1200 个 Windows 设置页和控制面板项。shipeiqi、“网卡”、ncpa.cpl 都能打开网络连接；另外补了组策略、磁盘管理、hosts、AppData 等开始菜单里没有的。

🌐 网页搜索 · ⭐ 收藏夹 · 🧩 插件

  • 网页搜索：baidu 天气、zhihu 显卡、jingdong 键盘，关键词加空格就在那个网站上搜。
    • 自带百度、必应、B 站、知乎、微博、抖音、小红书、淘宝、京东、翻译。
    • 可以用 %s 网址添加自己的网站，图标、列表都能导入导出。
    • 搜索建议：baidu 显卡 下面直接列出百度的联想词，Enter 搜它、Tab 填进框里；自己的网站也能填建议接口。图标可以选 SVG 文件，或直接粘贴 iconfont 的 SVG 代码。
  • 收藏夹：
    • 右键“加入收藏夹”，不打字时排在最前；
    • 起个关键词，一打就开；
    • 收藏的文件夹按 Tab 进去接着搜。
  • 插件：
    • 随包的小工具：= 1+2*3 计算器、12 inch to cm 单位换算、#ff8800 颜色，还有时间戳、UUID、Base64、哈希；
    • kill 结束进程，bm 搜浏览器书签，tr 翻译；
    • 按意思找（默认关）：? 去年报销的规定 也能找到写着“差旅费用申请”的文档。用你选的模型：本机的 Ollama、LM Studio 什么都不上传；硅基流动、百炼、OpenAI 等填自己的密钥，第一次计算前告诉你要发出去多少字，你按回车才开始。见 plugins/winshun.semantic；
    • 自己写插件：零代码的 plugin.json、任意语言的脚本或常驻进程都行，附 Python / PowerShell / C++ SDK；
    • 插件以普通权限、限内存运行。见 docs/plugins.md。

📂 “打开”“另存为”对话框

  • 对话框旁的搜索框：输入文件夹或文件名（拼音也行），回车，对话框直接转过去；网页上传文件、WPS 的对话框、VBA 宏弹出的“浏览文件夹”也认。
  • Ctrl+G：转到资源管理器、Total Commander、Directory Opus 或 XYplorer 正在显示的文件夹，和 Listary 的同名快捷键一样。
  • 不输入时：列出打开着的文件夹、刚复制的路径、收藏和最近用过的文件夹。
  • 自动转过去：可以设成对话框一出现就转到文件管理器的文件夹，或者先停在上次的位置，从文件管理器切回来时再转。

🗂️ 资源管理器里：双击空白处、右键搜索此处

  • 双击空白处：在资源管理器或桌面的空白处双击，弹出收藏的、最近的、别的窗口里开着的文件夹，选一个就在这个窗口里转过去（桌面上开新窗口），和 Listary 一样；还能在当前文件夹里搜、把它加进收藏。
  • 菜单不抢焦点，方向键、回车、Esc、首字母都能用；点别处或再双击就关。Listary 在运行时让给它。
  • Directory Opus 里也能双击：Win顺 可以替你在 Opus 的设置里加好这条命令（Opus 会重启一下），关掉或卸载时换回原来的。
  • 用快捷键弹出：双击被别的程序占了，或者想在 Total Commander、XYplorer 里用，就在设置里给文件夹菜单设一个快捷键，在任何窗口里按：资源管理器、桌面、Directory Opus、Total Commander、XYplorer、“打开”“另存为”对话框里选中的文件夹在那个窗口里打开，别的窗口里用文件管理器打开；再按一次关闭。
  • 右键“用 Win顺 搜索此处”：文件夹、文件夹的空白处和磁盘的右键菜单里都有（Windows 11 在“显示更多选项”里），搜索框带着这个文件夹打开，接着打字就在里面找。设置里可以关。
  • 直接打字搜索：在资源管理器的文件列表里随意打字，Win顺 就带着打的字、在这个窗口的文件夹里搜，和 Listary 一样；中文输入法照常组拼音，Esc 回到资源管理器。设置里打开（它代替了资源管理器自己的按首字母跳到文件，所以默认关）。

📋 剪贴板历史（代替 Win+V）

  • 记什么：复制过的文字、图片、文件都记下来。
  • 怎么打开：Win+V 或自设的快捷键；开在输入光标旁，不抢焦点。
  • 怎么粘贴：双击或 Enter 粘贴（也可以设成像 Windows 自带的那样单击就粘贴），Shift+Enter 粘贴为纯文本，Alt+1～9 直接粘贴第几条（按住 Alt 时序号显示在图标上）。
  • 能搜：拼音搜索，@wx 只看微信里复制的；图片里的字也能搜（PaddleOCR 文字识别，在本机，不联网，截图里的数字和小字也认得准）。
  • 预览：全文、大图、颜色值的 HEX / RGB / HSL；图片缩略图可以调大，不打开预览也看得清。
  • 拖出图片：按住一张图片拖到文件夹里，就存成 PNG 文件。
  • 整理：固定、分组、多选按顺序合并粘贴，钉住后可以一条接一条地往表格里填；固定的可以排在最前，顺序可以拖动或用 Ctrl+↑/↓ 自己排。
  • 隐私：密码管理器复制的密码不记录，历史只存在本机。

🔎 任务栏搜索框

  • 在 Windows 11 任务栏上放 Win顺 自己的搜索框（Windows 10 是固定一个按钮），结果从任务栏上方滑出。
  • 可以像 Windows 自带的搜索框一样放在开始按钮右边，图标往右让出位置（设置里打开，默认关），和 TranslucentTB 一起用也行。
  • 样式和 Windows 搜索一样三选一：整个搜索框、图标和“搜索”、仅图标（像任务栏上的一个按钮）。
  • 搜索框可以单独使用，也可以与 Windows 搜索并存；是否隐藏 Windows 搜索、接管 Win+S 或开始菜单打字，都按需选择。

🤖 AI 助手（MCP）

  • 能做什么：Win顺 是一个 MCP 服务器，AI 能用它搜文件名、文件内容和最近修改的文件。
  • 怎么连：Claude Desktop、Claude Code、Cursor、VS Code 在设置里一键连接。
  • 安全：
    • 默认只读，只看得到 AI 客户端自己有权限看的文件；
    • 可以设不让 AI 看到的文件夹；
    • 每次调用都有记录。

🎨 外观和设置

  • 外观：浅色、深色跟随系统，Windows 11 云母（Mica）效果；圆角或直角（直角和 Windows 10 一样）；图标在 150% 缩放下也清晰。界面大小有紧凑、标准、宽松三档，托盘和任务栏的图标可以换成单色。
  • 设置：可以搜索（Ctrl+F，kjj 找到“快捷键”），改了立即生效。
  • 文件管理器：打开文件夹、打开所在位置时用资源管理器、Total Commander、Directory Opus 或 XYplorer（装了的才列出）；别的文件管理器也行，在设置 › 打开 Win顺 › 对话框里填它的命令。
  • 备份：设置 → 高级里选一个文件夹（放在同步盘里就是云备份），设置、收藏、对话框的固定项、自己加的网页图标和插件会自动备份，保留最近 10 份，随时恢复。
  • 更新：有新版本时在托盘提醒，Win顺 不会自己下载、替换程序文件。

下载安装

  1. 到 Releases 页面 下载 WinShun-版本号-x64-setup.exe，双击安装。Windows 提示“已保护你的电脑”时，点 更多信息 → 仍要运行（还没有代码签名证书）。
  2. 装完托盘里出现 Win顺 的图标，索引几秒就建好。连按两下 Ctrl 开始搜索。
  3. 升级时运行新的安装程序，设置和索引都保留。卸载在 Windows 的“设置 → 应用”里。

不想安装的话，下载 WinShun-版本号-x64-portable.zip，解压到任意文件夹，运行里面的 WinShun.exe 就行。设置、记录、剪贴板历史和索引都存在它旁边的 data 文件夹里，整个文件夹可以拷到 U 盘或别的电脑；第一次启动时，这台电脑上原来的设置和数据（%APPDATA%\WinShun、%LOCALAPPDATA%\WinShun）会复制过来，原处的不动。升级时把新版解压到同一个位置覆盖，data 留着。删掉 data 文件夹（先退出 Win顺），就和安装版一样存在原来的地方。

系统要求：Windows 10 或 11，64 位。

管理员权限

  • 平时不用：Win顺 以普通权限运行。安装版带一个很小的“Win顺 索引服务”，由它读 NTFS 主文件表（MFT）和 USN 变更日志，所以照样几秒建好索引、实时跟上改动。安装时要管理员同意一次，之后登录和打开都不弹 UAC。
  • 能看到哪些文件：和 Everything 一样，索引里有整块盘的文件名，包括这台电脑上其他用户的；没有权限的文件照样打不开。
  • 便携版：默认一个个文件夹走一遍来建索引，第一次慢一些，之后实时跟上改动。在设置 → 索引方式里可以装上索引服务，或以管理员身份重新启动。
  • 管理员直读：管理员账户可以在设置 → 索引方式里选“管理员直读”，像旧版一样整个程序以管理员身份运行、直接读盘。
  • 以管理员身份运行的程序：Windows 不让普通权限的程序往它们里面打字。往这样的窗口里粘贴时，Win顺 只复制，提示你按 Ctrl+V；对话框旁的搜索框也不出现在这些程序上。
  • 打开的东西是普通权限：从 Win顺 打开的文件和应用都以普通权限运行，只有 Ctrl+Shift+Enter 才以管理员身份运行。

常见问题

和 Everything、Listary 有什么区别？ Win顺 自己建索引，不用装 Everything。文件名、拼音、应用和文件内容在一个框里搜，针对中文做了优化。对话框里有和 Listary 一样的 Ctrl+G 和搜索框，但不嵌进资源管理器窗口。

双击 Ctrl 和别的软件冲突？ Listary、PowerToys 的“查找鼠标”默认也用双击 Ctrl，关掉其中一边就行，或者让 Win顺 只认左 Ctrl 或右 Ctrl（设置 › 打开 Win顺 › 用哪个 Ctrl）。也可以在 Win顺 里改用别的组合键。游戏全屏、藏起鼠标时，Win顺 默认不响应双击 Ctrl。

AutoHotkey 改的键在 Win顺 里不起作用？ 选了“管理员直读”时，Win顺 以管理员身份运行，Windows 不让普通权限的程序拦截发给它的按键。换回别的索引方式，或用 AutoHotkey 的 UI Access 模式、以管理员身份运行脚本。

占多少内存？索引能不放 C 盘吗？

  • 内存：每 100 万个文件约 30 MB，用着的时候整个程序一般 120～140 MB；不用它一分钟后，任务管理器里降到十几 MB。
  • 索引位置：在设置 → 高级 → 索引位置里，可以移到其他内置硬盘。

索引很慢，或者出了问题？ 到 设置 › 高级 › 诊断日志 点“导出诊断日志”，把打开的文件夹里的 WinShun-diagnostics.zip 发到 GitHub Issues 或论坛。诊断包记的是版本、系统、磁盘、索引进度和错误，不含设置、剪贴板、搜索历史和文档正文。

收费吗？会上传数据吗？ 完全免费，MIT 开源。只在这些时候联网：到 GitHub 检查新版本（可以关掉）；第一次显示某个网页搜索或书签时取一次那个网站的图标；在网站关键词后打字时，把这些字发给那个网站取搜索建议（不打关键词时一个字也不发，可以在设置里关掉）；你自己打开“按意思找”插件并选了云服务时，把文档的文字发给你选的服务商。索引和历史只存在本机（%LOCALAPPDATA%\WinShun）。

English

WinShun (Win顺, "Windows made smooth") is a free, open-source search launcher for Windows. Press Ctrl twice and a search bar pops up, with results as you type:

  • find files and folders by name or by pinyin;
  • search the text inside Word, Excel and PDF files;
  • launch apps and open Windows settings.

It also brings a clipboard history, a search bar for file dialogs, a taskbar search box, plugins and an MCP server for AI assistants.

It reads the NTFS master file table (MFT) directly, indexing three million files in a few seconds and following every change live: no Everything install needed. It needs no account and uploads nothing. The interface comes in English and Simplified Chinese. Screenshots: above. A step-by-step guide to every feature (in Chinese): docs/使用说明.md.

Features

  • 🔍 File search
    • Speed: press Ctrl twice; a search over three million files takes milliseconds.
    • Pinyin: ndbg finds 年度报告; a mistyped homophone (年度报高) is retried by sound.
    • Where: all local drives, USB drives if you like (an unindexed one that is plugged in is offered at the end of the list), and NAS / SMB network shares, still searchable while their server is off.
    • Order: your own files first, the date modified on each row, Ctrl+S for best match / newest / oldest. Recent files are listed when the box is empty, or nothing if you like; the search can also start empty each time it opens.
    • Programs first: curl lists curl.exe before the folder curl and curl.h; which file types go first is yours to change (exe, bat, cmd, ps1 and msi to begin with, like Listary's preferred file types).
    • Shortcuts: Ctrl+1…Ctrl+9 opens a row; hold Ctrl to see the numbers on the icons (or show them always, or never).
    • Search panel: too many hits? The small button at the box's corner or Ctrl+E grows the same window into a panel, as Listary has it: filters down the left (scope, kind, date modified, size, folder), the rows in columns on the right (name, path, size, date modified) with sortable headers; with nothing typed it browses the whole index by those filters (milliseconds over three million files). size:>10mb and dm:7d work in the box too. Press it again to collapse.
    • Long names: a name that does not fit is shortened in the middle, keeping its extension and end ("…v3 final.xlsx"); rest the pointer on the row to see the full name, location, size, modified and created times. Drag the left or right edge of the search box to widen it (the width is remembered; double-click an edge for the default).
    • Pin: Ctrl+T or the pin at the box's corner keeps the search box up through clicks elsewhere and opened files; Esc closes it. Drag the window by the magnifier on the left; click it for the settings.
    • Preview: Alt+P on a result (or Preview in its menu) shows the file without leaving the launcher: pictures, text (UTF-8 or GBK, detected), Word, Excel, PowerPoint and PDF (through the same preview handlers as File Explorer's preview pane), what a folder holds; the arrows move it to the next row, Alt+P again or Esc closes it. QuickLook or Seer, when running in the background, shows it instead.
    • Thumbnails: pictures, videos, PDFs and the like show their thumbnail instead of their type's icon, in the results and in the search bar beside Open / Save dialogs; Settings › Result list can turn them off.
    • Context menu: right-click a row for its location, Copy path, Add to favorites and more; Shift+right-click (or More options in that menu) brings up Windows' own full context menu, as in File Explorer, for one row or several; after copy, cut or delete the search box stays open.
    • By kind: under Files, a row of kinds (folders, documents, pictures, videos, archives…); Ctrl+Tab steps through them, + adds your own.
    • Drag out: drag results into a chat, a mail or Explorer.
    • Live updates: the USN change journal is read, so renamed, new and deleted files are found at once; unplugging a USB drive never says it is in use.
    • Query syntax: "exact phrase", !exclude, !node_modules\, wildcards * ?, ext:pdf,docx, folder\name, and paths (D:\My Files\, tools/out/).
  • 📄 Full-text search
    • What: the Content scope searches inside txt, md, logs, source code and Word, Excel, PowerPoint, PDF and WPS files, showing the page, slide or sheet and row.
    • In one folder: add a folder's name and a slash, annual report abc/, to search only in folders named abc (/abc last works too; work/abc/ takes the one in work); folders of the same name are all searched and listed under the box, Ctrl+Tab picks one. Or pick a favorite folder there, or right-click a folder in the results → Search contents in this folder.
    • How: ranked by relevance, with a content index for speed; UTF-8, UTF-16 and GBK are detected. The first content index reads text files straight from the disk through the index service, so antivirus does not check them one by one and it is done much sooner. Files over the size limit, in system folders or of unlisted text types are skipped; the list says how many of each, and one click searches them too.
    • Safety: documents are read by a separate process with restricted rights.
  • 🚀 Apps and settings
    • Apps: everything in the Start menu (Store apps included), by name, pinyin, initials (vsc) or program file (winword).
    • Settings: about 1,200 Windows settings pages and Control Panel items (ncpa.cpl, “network adapter”), plus Group Policy, Disk Management, hosts, AppData and more.
  • 🌐 Web search: zhihu 显卡, baidu 天气: a keyword and a space search that site. Ten Chinese sites are built in; add your own with %s in the URL, and import or export the list and icons. The site's search suggestions show below as you type (Enter searches one, Tab puts it in the box), and a site's icon can be an SVG file or pasted SVG code.
  • ⭐ Favorites: right-click → Add to favorites. They come first when the box is empty; give one a keyword to open it, and Tab searches inside a favorite folder.
  • 🧩 Plugins
    • Bundled: = 1+2*3, 12 inch to cm, #ff8800, timestamps, UUID, Base64, hashes; kill processes, bm browser bookmarks, tr translation.
    • Search by meaning (off by default): ? last year's expense rules finds a document that says “travel cost requests”. It uses the model you pick: Ollama or LM Studio on your PC uploads nothing; for SiliconFlow, Model Studio, OpenAI and others you enter your own key, and before the first run it says how much text would be sent and waits for your Enter. See plugins/winshun.semantic.
    • Your own: zero-code plugin.json, scripts in any language, or resident processes, with SDKs for Python, PowerShell and C++. Plugins run with normal rights under a memory limit. See docs/plugins.en.md.
  • 📂 Open / Save dialogs
    • Search bar: a search bar under every file dialog; type a name (pinyin too), press Enter, and the dialog goes there; web page uploads, WPS dialogs and the "Browse For Folder" box of VBA macros too.
    • Ctrl+G: jumps to the folder open in File Explorer, Total Commander, Directory Opus or XYplorer, like Listary.
    • Suggestions: open folders, a path you just copied, favorites and recent folders.
    • Going there by itself: optional, as the dialog opens, or only when you come back to it from the file manager.
  • 🗂️ In File Explorer: a double click, a right-click
    • Folder menu: double-click the blank space of a File Explorer folder or of the desktop: favorite, recent and open folders; pick one and the same window goes there (the desktop opens a new one), like Listary. Also: search this folder, add it to the favorites.
    • It never takes the focus: arrows, Enter, Esc and first letters work; a click elsewhere or another double click closes it. It stays out of the way while Listary runs.
    • In Directory Opus too: WinShun can add its command to Opus's settings for you (Opus restarts once), and puts the old one back when turned off or uninstalled.
    • By a shortcut: when another program has the double click, or for Total Commander and XYplorer, give the folder menu a shortcut in the settings and press it in any window: in File Explorer, on the desktop, in Directory Opus, Total Commander, XYplorer and Open / Save dialogs the folder picked opens in that window; anywhere else, in your file manager. Press it again to close the menu.
    • “Search here with WinShun” on the right-click menu of folders, a folder's blank space and drives (under “Show more options” on Windows 11): the search window opens with that folder typed. It can be turned off.
    • Type to search: type anywhere in a File Explorer file list and WinShun searches that window's folder for what you typed, like Listary; a Chinese input method composes as usual, and Esc goes back to File Explorer. Turn it on in the settings (it replaces Explorer's own jump to a file by its first letters, so it is off by default).
  • 📋 Clipboard history (replaces Win+V)
    • What: text, pictures and files, opened with Win+V or your own shortcut, by the text cursor, without taking the focus.
    • Search: pinyin, @app filters, and words in copied pictures (PaddleOCR text recognition, on your PC and offline, good with numbers and small print in screenshots).
    • Preview: full text, pictures, HEX / RGB / HSL color values.
    • Drag pictures out: hold a picture and drop it on a folder to save it as a PNG file.
    • Paste: double-click or Enter, or one click as in Windows' own history (an option); larger picture thumbnails as another.
    • Organize: pins, groups, multi-paste in order, and Alt+1…Alt+9; pinned items can come first, and the order is yours to drag or move with Ctrl+↑/↓.
    • Privacy: passwords from password managers are not kept, and the history stays on your PC.
  • 🔎 Taskbar search box: WinShun's own search box on the Windows 11 taskbar (a pinned button on Windows 10), optionally right of Start where Windows' own box sits (alongside TranslucentTB too); a whole box, its icon and label, or its icon alone, as Windows' own search. It works on its own or alongside Windows search; hiding Windows search, taking over Win+S, and searching as you type in the Start menu are all optional.
  • 🤖 AI assistants (MCP)
    • What: WinShun is an MCP server. Claude Desktop, Claude Code, Cursor and VS Code connect in one click and search file names, file contents and recent changes.
    • Safety: read-only by default, limited to what the AI client may see, with folders kept from AI and a call log.
  • 🎨 Looks and settings
    • Looks: light and dark themes following Windows, Windows 11 Mica, rounded or square corners (square as in Windows 10), sharp icons at any scaling; compact, standard or roomy sizes, and a monochrome tray and taskbar icon if you like.
    • Settings: searchable (Ctrl+F); changes apply at once.
    • File manager: folders and file locations open in File Explorer, Total Commander, Directory Opus or XYplorer (those installed are listed), or in any other file manager whose commands you enter under Settings › Open WinShun › Dialogs.
    • Backup: choose a folder under Settings → Advanced (a synced folder makes it a cloud backup); settings, favorites, dialog pins, your own web icons and plugins are backed up as they change, the last 10 kept, ready to restore.
    • Updates: announced in the tray; WinShun never replaces its own files.

Download and install

  1. Download WinShun-<version>-x64-setup.exe from the Releases page and run it. If Windows says “Windows protected your PC”, click More info → Run anyway: the app is not code-signed yet.
  2. When the WinShun icon appears in the notification area, it is running; the first index takes a few seconds. Press Ctrl twice and type.
  3. To upgrade, run a newer installer: your settings and index are kept. Uninstall from Windows Settings → Apps.

To skip the installer, download WinShun-<version>-x64-portable.zip, unzip it anywhere and run WinShun.exe in it. Settings, history, clipboard and index are kept in the data folder beside it, so the whole folder can go on a USB stick or another PC; on the first start, what this PC already has (%APPDATA%\WinShun, %LOCALAPPDATA%\WinShun) is copied in, the originals left in place. To upgrade, unzip the newer one over it and keep data. Without the data folder (quit WinShun first), it keeps them where the installed copy does.

Requires Windows 10 or 11, 64-bit.

Administrator rights

  • Not needed day to day: WinShun runs with your normal rights. The installed version comes with a small “WinShun Index Service” that reads the NTFS master file table (MFT) and change journal (USN) for it, so millions of files are still indexed in seconds and changes followed live. An administrator approves the install once; after that there is no UAC prompt at login or when you open it.
  • Which files you see: as with Everything, the index holds the file names of whole drives, other users' on this PC included; files you have no rights to still won't open.
  • Portable version: by default it walks the folders one by one, so the first index is slower; changes are followed live after that. Settings → Index access can install the index service or restart it as administrator.
  • Direct as administrator: on an administrator account, Settings → Index access → “Direct (administrator)” runs the whole app as administrator and reads the drives itself, as earlier versions did.
  • Programs running as administrator: Windows doesn't let normal-rights programs type into them. Pasting into such a window only copies, and WinShun tells you to press Ctrl+V; the search bar beside file dialogs doesn't appear on them either.
  • What you open is not elevated: files and apps you open from WinShun run with your normal rights; only Ctrl+Shift+Enter runs one as administrator.

FAQ

How is it different from Everything or Listary? WinShun builds its own index, so Everything is not needed. File names, pinyin, apps and file contents are searched from one box, tuned for Chinese. File dialogs get Listary's Ctrl+G and a search bar, but WinShun does not embed itself in Explorer windows.

Ctrl twice clashes with another program? Listary and PowerToys' Find My Mouse use it too: turn it off on one side, let WinShun count only the left or the right Ctrl (Settings › Open WinShun › Which Ctrl), or give WinShun another shortcut. Full-screen games and games that hide the mouse are ignored by default.

AutoHotkey remaps don't work in WinShun? With “Direct (administrator)” chosen, WinShun runs as administrator, and Windows keeps normal-rights programs from intercepting keys sent to it. Pick another index access, or run the script with UI Access or as administrator.

Memory? Index location?

  • Memory: about 30 MB of index per million files; the whole app is usually 120–140 MB while in use, and drops to about 15 MB in Task Manager a minute after you stop using it.
  • Index location: the index can move to another built-in drive under Settings → Advanced.

Indexing is slow, or something is wrong? Under Settings › Advanced › Diagnostic logs, click “Export diagnostic logs” and attach the WinShun-diagnostics.zip from the folder that opens to a GitHub issue. It holds the version, system, disks, indexing progress and errors, not your settings, clipboard, search history or document text.

Is it free? Does it collect data? Free and MIT-licensed. It goes online only to check GitHub for new versions (you can turn that off), to fetch a web shortcut's or bookmark's site icon once, to ask a site for search suggestions while you type after its keyword (nothing is sent without a site keyword; you can turn this off), and, if you turn on the “Search by meaning” plugin with a cloud service, to send document text to the service you chose. The index and history stay on your PC (%LOCALAPPDATA%\WinShun).
