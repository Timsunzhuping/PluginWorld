Bizmoon plugins for Claude Code

Install:

/plugin marketplace add uofuonye/bizmoon-plugins
/plugin install bizmoon@bizmoon

Optional API key (Professional plan): export BIZMOON_API_KEY=bm_sk_... before starting Claude Code to unlock full history and organization tools.
