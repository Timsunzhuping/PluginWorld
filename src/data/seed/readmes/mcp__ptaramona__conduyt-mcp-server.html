Conduyt MCP Server

The official Model Context Protocol server for Conduyt CRM. It lets Claude, ChatGPT and any MCP-compatible AI agent work with your Conduyt account: contacts, deals, pipelines, tasks, automations, messaging, bookings and reports.

  • Product page: https://conduyt.com/mcp/
  • npm package: https://www.npmjs.com/package/conduyt-mcp
  • API docs: https://conduyt.app/docs

This repository mirrors the published npm package conduyt-mcp (version 4.71.0), which is the source of truth. It contains the compiled server in dist/.

Quick start

You need a Conduyt account and an API key. Create the key in Conduyt under Settings > API Keys. Keys start with cdy_.

Add Conduyt to your MCP client config (Claude Desktop: claude_desktop_config.json; Claude Code: .mcp.json):

{
  "mcpServers": {
    "conduyt": {
      "command": "npx",
      "args": ["-y", "conduyt-mcp"],
      "env": {
        "CONDUYT_API_URL": "https://conduyt.app",
        "CONDUYT_API_KEY": "cdy_your_key_here"
      }
    }
  }
}

Requires Node.js 18 or later. The server runs locally over stdio.

Authentication

Every tool call uses your API key. Keys support three tiers:

  • read: GET requests only
  • write: GET, POST and PATCH
  • admin: full access, including DELETE

Scopes can be restricted to specific modules (contacts, deals, tasks and so on). The agent can only do what the key allows; conduyt_check_permissions shows the current key's access.

Environment variables

Variable Required Description
CONDUYT_API_URL Yes Base URL, https://conduyt.app
CONDUYT_API_KEY Yes API key starting with cdy_
CONDUYT_TIMEOUT_MS No Request timeout in milliseconds
CONDUYT_MAX_RESPONSE_BYTES No Cap on the size of a tool result
