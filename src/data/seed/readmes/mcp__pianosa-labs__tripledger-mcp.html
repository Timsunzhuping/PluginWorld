TripLedger MCP server

A remote MCP server for your personal travel history. Connect Claude, ChatGPT, Cursor or any MCP client to TripLedger and keep a durable ledger of where you've been: journeys, stays and travel expenses, with tax-residency day counts and Schengen 90/180 status computed from your records.

  • Endpoint: https://my.tripledger.app/mcp (Streamable HTTP)
  • Auth: OAuth 2.1 (browser consent) or a tl_ API key
  • Docs: docs.tripledger.app

This repository contains connection instructions and configuration only. TripLedger is a hosted service; nothing here runs locally.

What you can ask

  • "Log my flight from this booking email: LHR → BCN on 14 March, back on the 21st."
  • "How many Schengen days do I have left if I travel to Lisbon on 2 June?"
  • "How many days have I spent in Spain this year, and in the last 365 days?"
  • "Where am I according to my travel ledger?"
  • "Find gaps in my 2025 travel history before I send it to my accountant."

Connect

Claude.ai / Claude Desktop (OAuth)

  1. Settings → Connectors → Add custom connector
  2. Paste https://my.tripledger.app/mcp
  3. Log in to TripLedger and approve. Each grant binds one ledger.

Claude Code (API key)

Create a key in TripLedger under Settings → API keys (shown once), then:

claude mcp add --transport http tripledger https://my.tripledger.app/mcp \
  --header "Authorization: Bearer tl_YOUR_KEY"

Other MCP clients

Clients that support remote OAuth: configs/mcp-oauth.json. Clients that need a header: configs/mcp-api-key.json.

Treat API keys like passwords. Revoke keys and OAuth grants anytime in TripLedger Settings → API keys / Connected apps.

Access and pricing

  • 14-day trial, then a one-time $97 lifetime license per ledger. No subscription.
  • After a trial ends the ledger is read-only: reads, calculations and MCP read tools keep working.
  • 5,000 MCP requests per ledger per day.
  • Writes need an owner or editor role; viewers get read tools.

Agent plugin

plugin/ is an Agent Plugins package: the MCP server plus a managing-tripledger workflow skill that teaches agents to capture travel from evidence, never invent records, and confirm before deleting.

Not

TripLedger is a ledger, not flight or hotel search, a booking service, or live location tracking. Results depend on the travel you record. They are informational, not tax or legal advice, and not a guarantee of admission at any border.
