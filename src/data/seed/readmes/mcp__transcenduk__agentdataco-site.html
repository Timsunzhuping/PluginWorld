agentdataco-site

Source for agentdataco.com: daily, archived data on the AI ecosystem (GitHub AI agent & MCP repos, the official MCP registry, Hugging Face trending, LLM pricing from OpenRouter, AI/SaaS pricing pages, Show HN AI launches), served as a REST API and a remote MCP server.
