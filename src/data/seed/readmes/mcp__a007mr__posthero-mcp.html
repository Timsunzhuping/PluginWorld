@posthero/mcp

MCP (Model Context Protocol) server for PostHero — schedule and publish social media posts from Claude Desktop, Cursor, VS Code, Windsurf, and any MCP-compatible AI tool.

Quick start

1. Get your API key

Sign up at posthero.ai and grab your key from Settings > API.

2. Add to your MCP client

Claude Desktop — edit claude_desktop_config.json:

{
  "mcpServers": {
    "posthero": {
      "command": "npx",
      "args": ["-y", "@posthero/mcp"],
      "env": {
        "POSTHERO_API_KEY": "pk_your_api_key_here"
      }
    }
  }
}

Cursor — edit .cursor/mcp.json:

{
  "mcpServers": {
    "posthero": {
      "command": "npx",
      "args": ["-y", "@posthero/mcp"],
      "env": {
        "POSTHERO_API_KEY": "pk_your_api_key_here"
      }
    }
  }
}

VS Code — edit .vscode/mcp.json:

{
  "servers": {
    "posthero": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@posthero/mcp"],
      "env": {
        "POSTHERO_API_KEY": "pk_your_api_key_here"
      }
    }
  }
}

3. Use it

Ask your AI assistant to post to social media:

"Schedule a LinkedIn post about our new feature launch for tomorrow at 9am"

"Create a Twitter thread about the benefits of remote work and publish it now"

"Show me my top-performing posts on Threads this month"

Available tools

Tool Description
list_accounts List connected social media accounts
create_post Create, schedule, or publish a post
list_posts List posts with filters (status, platform)
get_post Get full details of a post
update_post Update a draft or scheduled post
delete_post Delete a post from PostHero
publish_post Immediately publish a draft/scheduled post
get_analytics_summary Aggregated analytics for a platform
get_top_posts Top-performing posts ranked by metric

Supported platforms

LinkedIn, Twitter/X, Instagram, Facebook, YouTube, TikTok, Threads, Bluesky

Environment variables

Variable Description
POSTHERO_API_KEY Required. Your PostHero API key (pk_...)
POSTHERO_BASE_URL Override API base URL (default: https://server.posthero.ai/api/v1)
