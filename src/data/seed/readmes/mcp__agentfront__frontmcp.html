FrontMCP is the TypeScript framework for MCP servers. You write tools, resources and prompts as typed classes with Zod schemas, and FrontMCP serves them over the Model Context Protocol, with dependency injection, authentication, testing, agents and jobs, on Node, Vercel, AWS Lambda and Cloudflare Workers. It serves MCP 2026-07-28, the stateless revision, and the earlier ones. The docs, examples and a browser playground are at frontmcp.dev.

Write a tool. Ship a server.

Classes in, protocol out. FrontMCP handles transport, DI, sessions, auth and execution flow, and the same server runs locally and in production unchanged.

import 'reflect-metadata';

import { App, FrontMcp, Tool, ToolContext, z } from '@frontmcp/sdk';

@Tool({
  name: 'add',
  description: 'Adds two numbers together',
  inputSchema: { a: z.number(), b: z.number() },
})
class AddTool extends ToolContext {
  async execute(input: { a: number; b: number }) {
    return input.a + input.b;
  }
}

@App({ id: 'calc', name: 'Calculator', tools: [AddTool] })
class CalcApp {}

@FrontMcp({
  info: { name: 'Demo', version: '0.1.0' },
  apps: [CalcApp],
  http: { port: 3000 },
})
export default class Server {}

Start

npx frontmcp create my-app        # new project (Node 24+)
npx frontmcp init                 # or add FrontMCP to an existing one

Then follow Learn on frontmcp.dev, or browse Tools, Resources, Prompts, Agents, Auth, Plugins, Tool UI, Testing and Deployment. Try it live in the Playground.

Packages

Install frontmcp (CLI) and @frontmcp/sdk. The rest is pulled in for you, or opt-in. Keep every @frontmcp/* package on the same version: they depend on each other at exact versions.

Core and extensions
Package What it does
frontmcp CLI: create, init, dev, build, test, inspector
@frontmcp/sdk Core framework: decorators, DI, flows, transport, MCP protocol
@frontmcp/auth OAuth, JWKS, DCR/CIMD, sessions, credential vault
@frontmcp/testing E2E test framework with fixtures and matchers
@frontmcp/adapters Generate tools from an OpenAPI spec
@frontmcp/skills Curated SKILL.md catalog for scaffolding and skills install
@frontmcp/guard Rate limits, concurrency and policy guards
@frontmcp/observability Structured logging, metrics and tracing
@frontmcp/react React hooks and client for a FrontMCP server
@frontmcp/ui / uipack Widgets, SSR renderers, MCP Bridge, themes
@frontmcp/edge Run a server on Cloudflare Workers / V8 isolates
@frontmcp/storage-sqlite SQLite session, task and elicitation stores
@frontmcp/nx Nx generators and executors

Internal, published so the above resolve: protocol, di, utils, lazy-zod.

Official plugins
