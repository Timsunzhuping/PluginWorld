eonik gets you finished, on-brand ads without the busywork. Your designer makes the master; eonik makes the adapts: every size a media plan asks for, with your brand's fonts, rules and layout kept the same way on every size, checked, sent for approval and delivered.

The work runs in the eonik app on your Mac (download · macOS 15+ · Apple silicon), where your files and fonts are. Connect Claude, ChatGPT, Cursor, Codex or VS Code to it and ask in your own words; your assistant asks eonik, and eonik does the work on your computer. Nothing is made, changed or sent until you say so.

What you can ask

  • "Where are we?" What needs you, what is being made, what the client sent back.
  • "Adapt Elevation to the Bliss set, and add 1080x617." eonik makes every size and shows you each one before anything is final.
  • "Make the logo bigger on 300x250" · "Use the evening photo on every size."
  • "Is this OK to send?" The brand's rules on every size: the project's RERA line, the mark, the typeface, the smallest text, file-size limits.
  • "Send it to the client" · "What did Godrej say?"
  • "Kada Agrahara got its RERA number: PRM/KA/RERA/…" eonik saves it and prepares every creative that prints the old value.
  • "Check these Meta headlines" · "Package Bliss Set5 for media."

What it never does

It cannot pause, scale, launch or edit ads, and it cannot write to Meta, TikTok or Google Ads. It never says an ad "will work". It never makes a choice that is yours: making the sizes, approving, sending past a rule finding. Those are buttons you press, in eonik's panel or in eonik itself.

Connect

Claude (claude.ai, Desktop), ChatGPT, VS Code: add the connector https://api.eonik.ai/mcp and sign in with your eonik account; you choose the brand when you connect.

Hosts that run local servers (Claude Desktop's config file, Cursor, Codex): this package bridges them to the same server.

  1. Create an API key in eonik (Settings, API keys).
  2. Add this to the host's MCP config:
{
  "mcpServers": {
    "eonik": {
      "command": "npx",
      "args": ["-y", "eonik-mcp"],
      "env": {
        "EONIK_API_KEY": "eonk_live_...",
        "EONIK_BRAND_ID": "the brand this connection is about"
      }
    }
  }
}

EONIK_BRAND_ID is required if you have more than one brand: eonik never guesses which client's work you mean, and tells you the choices if it is missing. EONIK_API_URL defaults to https://api.eonik.ai.

The bridge forwards exactly what the server offers (tools, the panel, prompts and eonik's questions to you) and adds nothing of its own. Keep eonik open on your Mac while you work.

Security

Keep EONIK_API_KEY in your MCP host env. Do not commit it. See SECURITY.md.
