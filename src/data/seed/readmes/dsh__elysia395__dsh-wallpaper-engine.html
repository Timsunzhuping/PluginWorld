一个 DSH bundle，把你电脑上的 Wallpaper Engine 壁纸变成 DSH 网页界面（dsh web）的背景。

壁纸 + 磨砂遮罩 + iOS 液态玻璃，渲染在 DSH 界面后方。

能做什么

它会自动发现你本机的 Wallpaper Engine 安装，列出你的壁纸，并把可移植的类型渲染到 DSH 对话界面后方的固定图层，配以 iOS 风格的液态玻璃界面改造。

版本号、issue 号与性能数字一律记在 docs/CHANGELOG.md。

壁纸渲染（核心）

  • 三类壁纸，三条渲染路径：Video 直接播放；Web / HTML 走内置 WebWallGL 的网页挂载（宿主注入 WE API + 严格沙箱隔离）；Scene（场景） 由内置 WebWallGL 实时 WebGL 引擎渲染 —— 粒子系统、puppet 骨骼模型、SceneScript 脚本、鼠标视差与点击交互、包内音频与音频反应。
  • 实时优先、逐级降级：渲染页有心跳看护，首帧超时或运行失联就按「内嵌 MP4 → 实时抓帧 → 自定义画面 → 空态」逐级回退，并按壁纸记住失败（设置里重开开关即重试）。首帧之前不留黑屏：垫底画面按「实时抓帧 → 作者的预览图（WE 里那张缩略图）→ 主题色」取 —— 预览图只作占位、不算"替作者猜一张图"；一级都取不到时才诚实留空。
  • 高帧率源可降载：帧率上限把 4K120 这类源一次性转成上限帧率（4K 保留 + AV1），实测 GPU 占用从 ~60% 降到 ~15%；遮挡暂停三档在最小化 / 失焦 / 电池供电时直接停解码。
  • 能搬的都搬：本地 JPG / PNG / MP4 可直接上传当壁纸；自定义轮播列表按各自的间隔与顺序自动换壁纸（就绪后才切，不黑屏）。

界面改造（核心）

  • 整个设置窗口液态玻璃：DSH 原生设置窗口整体（对话框 + 左导航 + 全部原生分区）换成液态玻璃，配色、玻璃底色、透明度、雾化都可调。
  • 文字面保底：承载文字的面固定压一层主题底色，最坏情况正文对比度 4.63:1 —— 滑条调到极端也不会把字压得看不清。
  • 字体与光标可细调：字体按颜色角色 / 排版角色 / 组件三层细化（字号、字重、字族各自可设）；输入光标独立取色。整套外观可存成字体集（随包自带预设，可新建 / 重命名 / 删除 / 恢复原样，也能导出导入 .json 分享）。
  • 壁纸与界面融合可细调：壁纸模糊、亮度 / 对比度 / 饱和度、壁纸透明度、暗化、边框、雾化，全部即时生效。

特色功能

  • 吉祥物：聊天顶部一条可拖拽的拉绳，向下拉出壁纸仓库抽屉（两套立绘、可缩放），快捷调节随身可用。
  • 侧边栏液态玻璃：为 dsh-better-sidebar 的侧边栏专门适配（毛玻璃、高光与层级统一），另有一组独立的侧栏玻璃控制。

更新前置条件

⚠️ 更新本插件前，先把 DSH 内核与 dsh-better-sidebar 更新到最新，顺序不能反（先更新插件会遇到不兼容的 API）。完整的版本矩阵、三步顺序与「顺序反了怎么恢复」见 docs/UPGRADING.md。

支持哪些壁纸类型？

Wallpaper Engine 本体把壁纸分四种类型；本插件支持其中的三类：

类型 由谁渲染 能否搬到 DSH
Scene（场景） Wallpaper Engine 自带的 3D 引擎 ✅ 实时渲染 — 内置 WebWallGL WebGL 引擎（粒子 / 脚本 / 视差 / 包内音频）；失败按出图来源链降级
Web（网页） Wallpaper Engine 内置的 HTML/JS 运行时 ✅ 实时渲染 — 内置 WebWallGL 的网页挂载 + 注入 WE API（音频监听/属性/媒体），严格沙箱隔离；失败自动回退兼容 iframe
Video（视频） Wallpaper Engine 内置播放器 ✅ 直接播放 — 走上传视频同一套硬化管线（转码、解码帧率上限、遮挡暂停、倍速/翻转）
Application（应用） Wallpaper Engine 启动第三方可执行程序 ❌ 不支持 —— 它要宿主直接运行外部程序，本插件不提供该能力

四类壁纸各自的渲染路径、优雅降级、出图来源链与空帧门禁、以及排查用的诊断行， 见 docs/HOW-IT-WORKS.md。

工作原理

一句话：宿主（lib/index.js + lib/routes/*.js）负责找到 Wallpaper Engine 与你的壁纸库、 把媒体按需喂给浏览器；客户端（lib/client.js）负责把选中的壁纸挂到应用三列后方的固定图层， 并在「设置」里注册一个一级页签「Wallpaper Engine」。

出图来源链（实时渲染 → 内嵌 MP4 → 实时抓帧 → 自定义画面 → 空态）、宿主/客户端分工、 全部 HTTP 路由表、以及"为什么没有 CPU 兜底出图"的设计理由，都在 docs/HOW-IT-WORKS.md。实现细节以代码注释为准（本仓「代码即真相」）。

安装

普通用户（安装已发布版本，推荐）

如果你只是想用这个插件，直接装 npm 上已发布的包即可：

dsh plugin --profile web add dsh-plugin-wallpaper-engine

装完重启 dsh web，打开 设置 → Wallpaper Engine 就能用。

macOS / Linux 用户：本插件在 Windows / macOS / Linux 上原生可用 —— 三平台装的是同一个包、同一条命令（媒体链路也各自原生：GSMTC / MediaRemote / MPRIS）。

macOS 没有 Wallpaper Engine 客户端，因此扫不到 Steam 壁纸库：把「自定义壁纸」的存储位置指到一个装着 WE 工程目录的文件夹（project.json + scene.pkg / index.html / *.mp4），里面的场景 / 网页 / 视频壁纸会照常收录、场景同样实时渲染；也可以直接上传图片 / 视频。

开发者（运行你本地的一份代码）

用 link: 装本地一份代码、构建与验证、热挂载与编码铁律（含 lib/client.js 到底是什么）见 CONTRIBUTING.md。宿主端改动要重启 DSH 才生效（CLI 装的走 --profile web，桌面端走 --profile desktop 且必须先完全关闭应用）。

安装失败排查

装不上（ERR_PNPM_UNEXPECTED_VIRTUAL_STORE 等）的逐步处置，见 docs/TROUBLESHOOTING.md。

使用

  1. 打开 dsh web，进入 DSH 界面。
  2. 打开 设置，左侧导航里找到 Wallpaper Engine（一级设置页，侧边栏独立入口）；聊天顶部的拉绳吉祥物也能拉出「壁纸仓库」抽屉，两处共用同一套页签与调节项。
  3. 点 选择壁纸 打开弹窗，在缩略图网格里点选一张（**Application（应用）**类壁纸不支持，不显示在网格中）；点遮罩、按 ESC 或点「关闭」收起弹窗。
  4. 用 暂停/播放 控制视频壁纸，用 关闭 清除壁纸。全部选择与调节都会即时生效并持久保存（见 配置）。

设置界面：液态玻璃卡片，六个页签（壁纸 / 外观 / 吉祥物 / 效果 / 声音 / 高级）。

选择弹窗：浏览全部壁纸缩略图，支持批量隐藏与已隐藏恢复。

设置的页签

设置页与壁纸仓库抽屉共用同一套六个页签 —— 壁纸（选择 / 轮播 / 自定义）· 外观 · 吉祥物 · 效果 · 声音 · 高级，每页只保留与它相关的控件，不再是一列三十项的长滚动。页签指示胶囊随选中项平滑滑动，长说明一律收进控件悬停提示（tooltip），行内只保留一句话简述。

选择与过滤

  • 隐藏 / 恢复：卡片右上角的「隐藏」只把壁纸从列表移除，不删除源文件；弹窗的「已隐藏」标签可单张恢复或全部恢复，「批量」进入多选模式。隐藏当前壁纸不会打断播放，自动轮播也会跳过它。
  • 内容分级：按壁纸的 contentrating 字段（WE 壁纸读 project.json，自上传内容读 uploads/.meta.json）分 全部 / Everyone（默认）/ PG13 / Mature / 未分级；自上传内容未标注时按 Everyone 处理。这个字段由插件直接扫盘读取，不跟随 WE 客户端里的成人内容开关。
  • 类型：按可内嵌类型筛选 —— 全部 / 视频 / 网页 / 图片（自上传）/ 场景。
  • 每个选项都带当前可播放数量；被过滤掉的壁纸会从网格、轮播编辑器与轮播候选中整体剔除，也不会被自动选中或轮换。

卡片样式与播放控制

  • 紧凑布局（「高级」页签开关）：开启即 CD 架效果 —— 卡片纵向层叠、悬停放大置顶、一页到底不翻页；关闭为常规网格（默认）。
  • 黑胶唱片：选择界面旁旋转的黑胶把当前壁纸封面当唱片标签，播放时旋转、暂停即停；经典与紧凑两种卡片样式下都显示。
  • 倍速：视频壁纸 0.5x / 0.75x / 1x / 1.25x / 1.5x / 2x，基于浏览器原生 playbackRate，即时生效、不重载不黑屏。
  • 水平翻转：视频、网页与上传的图片 / 视频都生效（CSS scaleX(-1)，零主线程开销）。
  • 切换过场：换壁纸（手动点选与自动轮播共用）可选的转场动画 —— 硬切（默认） / 交叉淡化 / 推移 / 擦除 / 光圈 / 缩放 / 条带，每种自带基准时长，再乘「快 / 标准 / 慢」三档，方向型过场另有方向可选；系统开启「减少动态效果」时一律按硬切处理。

适配目标（宿主形态）

「高级」页签的适配段自动识别插件跑在 原生浏览器 / 非官方桌面端 / 官方桌面端 哪一种里，并显示「检测到：… · 有 / 无能力头栅栏」；检测不准时可手选覆盖 —— 手选优先于检测。判定与操作系统无关：宿主按请求头与 UA 观测（能力头 x-dsh-desktop-renderer ⇒ 非官方桌面端，UA 含 Electron/ ⇒ 桌面壳，两者皆无 ⇒ 原生浏览器），观测结果用只增不减的闩锁记住。它同时决定四件事：网页壁纸载荷走独立媒体源还是应用源（原生浏览器没有栅栏，就不再多开一个 loopback 监听）、桌面壳材质规则是否生效（一律经 [data-we-adapter^="desktop-"] 门控，浏览器形态不吃壳层材质）、「窗口失焦时暂停」是否提供（见下），以及面板各行的显隐与警示（手选与检测冲突时直接说明后果，例如手选浏览器却观测到栅栏 ⇒ 网页壁纸会 403）。

省电与降载

「高级」页签的遮挡暂停三档（默认：最小化 / 切页 开、窗口失焦 关、使用电池 关）：命中时机时视频壁纸直接停解码（不靠浏览器节流，解码引擎归零），场景实时渲染同时暂停渲染循环；回到界面 / 接通电源自动继续（手动暂停过的不会被自动恢复）。其中**「窗口失焦时暂停」只在适配目标为「原生浏览器」时提供** —— 桌面壳失焦时壁纸多半仍整块可见，按失焦暂停会定格可见画面；该档的值不会被删掉，切回浏览器目标即恢复生效。

「效果」页签的帧率上限（无限制 / 60 / 48 / 30 / 24 fps）针对高帧率源：宿主用 ffmpeg 一次性把源转成上限帧率（时间线保持 1.0x 正常速度、与倍速完全解耦），输出 4K 保留 + AV1，缓存后同一张壁纸只付一次成本。播放时先播原片、转好自动切换，设置页有实时进度条；源帧率已在上限内会自动跳过，转码失败自动回退原片。

ffmpeg 三档供给：显式指定（DSH_WE_FFMPEG 或插件目录下的 ffmpeg/）→ 自动下载（npmmirror + GitHub 双源竞速，校验后缓存）→ 系统 PATH。编码器优先 NVENC（av1_nvenc → h264_nvenc），无 NVIDIA 显卡时回落 libx264 软件编码（慢，但能出片）；只有连 ffmpeg 都拿不到时该功能才自动关闭，壁纸保持原片，不影响其它任何功能。

画面调节

「效果」页签（壁纸激活后）与「外观」页签的「细节」段提供八个滑动条：壁纸模糊 · 亮度 / 对比度 / 饱和度（壁纸媒体滤镜）· 壁纸透明度（整层淡出、融向页面底色，与暗化互补）· 暗化（加深壁纸与文字之间的遮罩）· 边框（边框 / 分割线对比度）· 雾化（玻璃面板模糊半径）。全部即时生效、持久保存，无需刷新页面；每个控件的取值范围与默认值直接看控件本身。

浅色 / 深色由壁纸自己决定 —— 换壁纸后插件会自动切到与壁纸相配的那一侧（取色顺序：作者的 schemecolor → 画面占比最大色（作者预览图与真实渲染帧各判一次，不一致时取深色）→ 取不到就保持不动；判定按颜色深浅，只有明显偏亮才用浅色。作者填的恰好纯黑算"没填"，会改用画面主色）。你也可以随时在 DSH 里手动改主题 —— 改过之后本张壁纸不再自动，换下一张恢复。偏亮或花纹复杂的壁纸看不清字时调高 暗化 / 边框（必要时加一点 壁纸模糊），嫌壁纸抢眼则调高 壁纸透明度。滑条再怎么调也不会把正文压到看不清 —— 承载文字的面都有可读性下限（见上）。

实时渲染与壁纸属性

场景 / 网页壁纸默认走内置 WebWallGL 实时渲染（lib/webwallgl/，MIT，源自 webwallgl）：粒子系统、puppet 骨骼模型、SceneScript 脚本、鼠标视差 / 点击交互、包内音频与音频反应完整还原。渲染页跑在同源隔离 iframe 里并有心跳看护，失败按壁纸记住并自动降级（设置里重开开关即重试）。网页壁纸另有注入的 WE API（音频监听 / 属性 / 媒体），并强制 sandbox="allow-scripts" —— 第三方 HTML 拿不到 DSH 的 origin。

当前壁纸是场景或网页时，「当前壁纸」卡片上会出现绿色的 壁纸属性 按钮：列出作者在 WE 编辑器里定义的可调属性（颜色 / 开关 / 滑块 / 下拉 / 文本 / 文件），改一下立刻生效并按壁纸记住，「恢复默认」一键清掉这张壁纸的全部改动；面板显示的是真正生效的值（从渲染页读回）。

自定义壁纸与自动轮播

  • 自定义壁纸：上传本地 JPG / PNG / MP4 当壁纸（浏览器与宿主端双重校验）。存储位置默认 ~/.dsh-wallpaper-engine/uploads，可改到任意盘符（绝对路径，支持 ~）并自动迁移已有文件；适配模式有覆盖 / 填充 / 居中 / 拉伸四种。上传的 MP4 按需抽帧生成缩略图；重复上传同一文件按内容识别、直接复用已有的那张。
  • WE 项目目录：存储位置里含 project.json 的壁纸项目目录（含 scene.pkg / index.html / *.mp4）会被自动收录成对应类型，场景壁纸同样走实时渲染；这些目录只读，不参与上传管理，也不会被删除。
  • 自动轮播：轮转基于自定义轮播列表 —— 用 新建 建任意多个列表，从库存勾选壁纸加入，每个列表单独设切换间隔（1 / 5 / 10 / 30 / 60 / 120 分钟）与播放顺序（顺序 / 随机），再勾选 自动轮转 只在该列表内循环。每个列表至少需要 2 张可播放壁纸；首次使用时插件会把第一个可播放的 WE 播放列表导入成一个列表，编辑时也可用 从 WE 播放列表导入。
  • 就绪后切换：到点先在后台把下一张准备到完全就绪（实时渲染首帧 / 视频可播放 / 图片解码完成）才落实切换 —— 旧壁纸在准备期间原样保持，就绪瞬间新旧两层交叉淡化，上屏即是活画面、不黑屏闪烁；准备失败的候选自动跳过、链式尝试下一张。

液态玻璃外观（整个设置窗口 + 配色 + 透明度）

字体与输入光标

「外观」页签下两个互不依赖的分区：

  • 全局字体 —— 总开关默认关闭（即 dsh 原生外观）。开启后按角色 / 按组件细化（没有全局字重、也没有全局字体族 —— 一个全局值会把 DSH 的粗细与字族层次压成一档）：
    • 文字颜色角色：按 DSH 的颜色角色分别上色（未设置 = 用 DSH 默认色）；
    • 排版角色：一行一个角色，列出字号 / 字重 / 字体三项 —— 字号是绝对值 px（输入框直接显示 DSH 官方字号，留空 = 不改），字重 100–900，字族 7 选 1（「跟随」= 不覆盖），另有「只看改过的」过滤器；
    • 高级字体设置（子开关）：按组件细化 代码块 / 终端 / markdown / 表格 四项 —— 只对启动自探测命中的组件生效（DSH 改名即整条降级，不误伤）。
    • 字体集预设：把整套字体外观存成一份字体集 —— 随包自带预设，可新建（以当前外观）/ 重命名 / 删除；改任何一项都只落到当前这一套，随时可以「恢复原样」回到它本来的样子；也能导出 / 导入 .json（导出走系统「另存为」）。它是「字体自定义」的附属：关掉总开关即整块收起。 报错 / 危险 / 警告语义元素强制保留系统红字；「恢复默认」一键清掉全部字体自定义项（不影响「只看改过的」这类视图开关）。
  • 输入光标 —— 壁纸透过液态玻璃输入框衬在光标后面、两者颜色相近时光标会「隐形」（#83），这里给光标一个独立颜色：自动（默认，恢复 dsh 原生）/ 6 种预设 / 自定义取色，经 caret-color 作用于所有文本输入位。

系统音频反应与歌曲信息（Now Playing）

「声音」页签三项（前两项默认开启，第三项默认关闭）：

  • 系统音频反应 —— 把系统正在播放的声音（任何 App，不只是浏览器标签）做成频谱喂给壁纸的音频反应效果。采集的是系统输出回环、不是麦克风，macOS / Windows / Linux 三平台都内置（Windows 走 WASAPI 回环，不再需要「立体声混音」或虚拟声卡）；拿不到音频时壁纸自动回落内置的模拟频谱。
  • 媒体信息 —— 把系统 Now Playing（歌名 / 歌手 / 专辑 / 播放态 / 进度 / 时长 / 封面）交给壁纸：依赖 WE 官方 wallpaperRegisterMediaPropertiesListener / …ThumbnailListener / …PlaybackListener（以及 …TimelineListener），识别这些 API 的工坊网页壁纸会自动显示歌曲信息与封面。
  • 在线歌词 —— 优先取本地的（音频同目录的 .lrc 与已缓存歌词）；开启后本地没有才向 lrclib.net 查一次 —— 那次请求会把歌名 / 歌手 / 专辑发出去，所以默认关闭。

这些数据由宿主侧自带的 Rust 中间件 media-bridge 子进程提供（随插件按需下载、校验 sha256 后执行，缓存在 ~/.dsh-wallpaper-engine/bin/）：macOS 用 MediaRemote、Windows 用系统媒体会话（GSMTC）、Linux 用 MPRIS over D-Bus。因此不再需要 brew install media-control、playerctl 或 VB-Cable，macOS 也不再需要 Xcode Command Line Tools；中间件取不到或起不来时自动回落到内置实现，原因写在 GET /wallpaper-engine/media-status 的 fallback 字段里。

配置

本插件不会向模型暴露任何工具或提示文本，对 agent 零 token 开销，也不写入任何 DSH 自身的设置。本地落盘只有三类：宿主端配置文件 ~/.dsh-wallpaper-engine/config.json（选择、隐藏、轮播、配色、字体等全部设置，以及你选的上传目录）、自定义壁纸文件本身，以及 ~/.dsh-wallpaper-engine/ 下的缓存与按需下载的运行时（抽帧转码 / 实时抓帧 / 视频缩略图缓存、ffmpeg 与媒体中间件的二进制）。

环境变量：

变量 作用
DSH_WE_FFMPEG 指定 ffmpeg 可执行文件（解析链最高优先）
DSH_WE_FFMPEG_URL 替换自动下载源（自建镜像 / 代理加速）
DSH_WE_CACHE_DIR 覆盖缓存根目录（抽帧转码缓存 / 实时抓帧缓存）
DSH_WE_STEAM_ROOT 显式指定 Steam 根目录（逗号/分号分隔，Windows 或 /mnt 路径；注册表/自动探测失效时的兜底）
DSH_WE_MEDIA_BRIDGE 指定媒体中间件的可执行文件（开发/自备产物；解析链最高优先）
DSH_WE_MEDIA_BRIDGE_URL 替换中间件下载源（自建镜像 / 代理加速；支持 {tag} / {asset} 占位符）
DSH_WE_MEDIA_BRIDGE_TAG / DSH_WE_MEDIA_BRIDGE_SHA256 换用其它版本的中间件（自定义版本必须同时给出 sha256，否则拒绝执行）
DSH_WE_MEDIA_LEGACY =1 强制使用内置实现（对比排查用）
DSH_WE_MEDIA_NO_AUDIO =1 只取歌曲信息、永不碰系统音频采集（不申请授权）
DSH_WE_MEDIA_PROVIDER =mock 用中间件自带的假播放器联调（不需要真播放器）
DSH_WE_MEDIA_IDLE_MS 空闲多少毫秒后停掉中间件子进程（0 = 不停；默认 15 分钟）
DSH_WE_MEDIA_DEBUG =1 把中间件的 stderr 与启动参数打到宿主日志
DSH_WE_DATA_DIR 覆盖插件数据目录（默认 ~/.dsh-wallpaper-engine；自检脚本用它隔离，避免写到你真实的 config.json）
DSH_WE_UPLOAD_DIR 覆盖自定义壁纸的存储位置（优先于设置里的「更改」与默认目录）
DSH_WE_ASSETS_DIR 覆盖「官方资源路径」（WE 的 assets 树；优先于设置里那一项）
DSH_WE_TRANSCODE_TIMEOUT_MS 覆盖单次转码的墙钟预算（毫秒；默认 15 分钟）

设置存在哪：从 v0.4.0 起全部设置存在宿主端文件 ~/.dsh-wallpaper-engine/config.json（与浏览器端口无关， 重启 / 换端口 / 清浏览器数据都不会丢；老版本的 localStorage 配置会自动迁移）。文件位置、多设备共享与读写行为见 docs/UPGRADING.md 的「设置持久化」。

与 dsh-better-sidebar 的兼容适配

本插件的液态玻璃效果对 dsh-better-sidebar 的侧边栏面板做了专门适配（毛玻璃、高光与层级统一），让侧边栏与对话区共享同一套「壁纸 + 遮罩」背景，三列视觉一致、不再割裂。

「外观」页签还提供一组独立于会话玻璃和当前壁纸的侧栏玻璃细粒度控制：即使没有启用 Wallpaper Engine 壁纸，也可以在普通 DSH 背景或其他背景来源上调整侧栏。它只作用于 dsh-better-sidebar 的侧边栏子树；不支持 backdrop-filter 的浏览器会自动回退到高不透明实色。

控件 作用 范围 默认
侧栏液态玻璃 总开关：把侧边栏面板换成液态毛玻璃 开 / 关 开
侧栏模糊 侧边栏毛玻璃的模糊半径 0–200 px 16
侧栏透明度 侧边栏玻璃的浓淡（越大越透：0 最实 / 200 最透） 0–200 % 120 %
侧栏玻璃颜色 侧边栏玻璃的底色色调 6 预设 + 自定义取色 #ffffff 白

侧栏玻璃与设置窗口玻璃是两套独立参数：会话玻璃的「玻璃」滑杆只管输入栏/气泡，侧栏玻璃滑杆管侧边栏。关闭「侧栏液态玻璃」会连同编辑器/终端内容面一起恢复原生样式。侧边栏默认较透（与背景观感一致、避免面板发白）；编辑器/终端等内容面另有独立的近不透明底色 + 透明度控制，保证窄面板里文字可读。

侧边栏液态玻璃适配与「外观」页签的字体自定义（行楷）同时生效的实际观感。

已知限制

  • **Application（应用）**类壁纸不支持 —— 它要宿主直接运行第三方可执行程序，本插件不提供该能力，因此不显示在缩略图选择器和轮播候选中。**Scene（场景）**壁纸由内置 WebWallGL 引擎实时渲染，不需要 Wallpaper Engine 在后台运行。
  • 浏览器需能自动播放静音 <video>（DSH 跑在 loopback，现代浏览器允许静音自动播放）。
  • 媒体从你本机的 Wallpaper Engine 安装路径提供；host 只提供它已枚举过的文件，不会暴露任意文件系统。自定义上传的文件同样只存在于本机，不上传任何服务器。
  • 抽帧转码依赖 ffmpeg：编码器优先 NVENC（av1_nvenc → h264_nvenc），无 NVIDIA 显卡时回落 libx264 软件编码（慢但可用）；只有拿不到 ffmpeg（含自动下载不可用，如 musl/Alpine 等未覆盖平台）时，帧率上限功能才自动关闭，壁纸保持原片播放，不影响其它任何功能。
  • 遮挡暂停对视频壁纸与场景实时渲染生效：视频壁纸直接暂停解码；场景实时渲染经控制面暂停渲染循环（GPU 占用随之回落）。纯网页（iframe）壁纸无法从外部暂停，只能随页面隐藏被浏览器节流。
  • 选择器文案为中英混合（本 bundle 尚未接入 DSH 的 locale 命名空间）。
