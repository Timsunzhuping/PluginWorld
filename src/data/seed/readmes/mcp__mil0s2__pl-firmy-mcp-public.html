pl-firmy — MCP server for checking Polish companies

Hosted remote MCP server that gives AI assistants verified data on Polish contractors straight from official registries: MF Biała lista podatników VAT, KRS, and EU VIES — plus a payment audit PDF and daily contractor monitoring.

  • Endpoint (Streamable HTTP): https://api.almmity.com/mcp
  • Auth: Authorization: Bearer <API key> (or X-API-Key). Free key (100 calls/month): https://api.almmity.com/#klucz
  • Tool discovery (initialize, tools/list) works without a key; tool calls need one.
  • Plans: Free 0 zł · Pro 59 zł/mies. · Biuro 199 zł/mies. — https://api.almmity.com/#cennik

Tools

Tool What it does
check_vat_whitelist MF VAT white list (Biała lista): VAT status, registered bank accounts, optional check that a given account belongs to the NIP
get_krs_extract Current KRS extract: legal form, board/representation, capital, address
find_company Find a company by NIP, REGON or KRS number
vies_check EU VIES VAT number validation
contractor_due_diligence One-shot check of all sources with a risk summary (OK / WARN / STOP)
payment_audit_report PDF report proving the payment check (art. 117ba Ordynacji podatkowej / split payment due diligence)
add_watch / list_watches / remove_watch Daily monitoring of contractors with e-mail/webhook alerts on status or bank-account changes

Connect

Claude Desktop / any stdio client (via mcp-remote) — see examples/claude_desktop_config.json:

{"mcpServers":{"pl-firmy":{"command":"npx","args":["-y","mcp-remote","https://api.almmity.com/mcp","--header","Authorization: Bearer ${PLF_API_KEY}"],"env":{"PLF_API_KEY":"plf_..."}}}}

Cursor (~/.cursor/mcp.json), VS Code, Claude Code: see examples/.

claude mcp add --transport http pl-firmy https://api.almmity.com/mcp --header "Authorization: Bearer plf_..."

Data sources & limits

Data is fetched live from public government APIs (wl-api.mf.gov.pl, api-krs.ms.gov.pl, ec.europa.eu VIES) and cached briefly. The service is not affiliated with the Ministry of Finance or the Ministry of Justice. Results are informational; the PDF report documents the check at a given time.
