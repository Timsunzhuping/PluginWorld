mailsocket SDKs & MCP server

mailsocket is an inbox API for OTP and magic-link signup automation: email in, JSON out. GET /inboxes/{id}/messages/wait?require=otp blocks and returns the OTP the instant it arrives — no polling, no IMAP. Built for signup automation, E2E tests, and AI agents.

This repo holds the official client packages.

Package Install Docs
Python pip install mailsocket python/
TypeScript / Node npm i mailsocket-sdk typescript/
MCP server (AI agents) uvx mailsocket-mcp mcp/

Full docs: mailsocket.app · dash.mailsocket.app/docs/

MCP config

Point any MCP-compatible client (Claude Desktop, Cursor, Claude Code) at the mailsocket-mcp server over stdio:

{
  "mcpServers": {
    "mailsocket": {
      "command": "uvx",
      "args": ["mailsocket-mcp"],
      "env": {
        "MAILSOCKET_API_KEY": "ms_live_..."
      }
    }
  }
}

See mcp/README.md for per-client config file locations and the full tool list.
