One request to your AI, one finished deliverable back: the PRD, the stakeholder update and the decision call, at a senior product manager's standard.

Your landlord kept your deposit. You got laid off on a Tuesday. Your boss wants the PRD by Friday. Generic AI is a very confident intern. PM Skills is the senior colleague's notes: 1285 of them, one markdown file each. (PM stands for Professional. Yes, we get asked.)

PM Skills is an open-source library of 1285 Agent Skills — plain-markdown SKILL.md files that teach an AI assistant to do one professional task to a senior professional's standard, from writing a PRD to decoding a lease or running a blameless postmortem. Each skill bundles the framework, an output template, quality checks, and anti-patterns. It is MIT-licensed and works with Claude, ChatGPT, Gemini, Cursor, and Codex.

🧭 How it works

A skill is one plain-markdown SKILL.md file: a description that tells your assistant when to load it, plus the working framework, output template and quality checks it follows. The installer (npx pm-claude-skills add) copies the skills you choose into the config folder of the tool you use, so they load only when a request matches. The MCP server serves skills on demand to any MCP client instead, and the same package exposes a read-only REST API for n8n, Make and other automations. No runtime, no account, nothing resident: uninstalling deletes text files.

✅ Trust and quality

An honest summary of what is checked, measured and still unreviewed, computed from the repo on every change:

  • Checked on every change, in CI: structure (SkillCheck, all 1,285 skills at the L3 gate), a security audit, a near-duplicate check, a count-drift check, translation parity (178 translations in 10 languages), and a prompt-injection suite of 15 hostile documents. A change that fails any of them does not merge.
  • Eval cases: 389 of the 1,285 skills carry eval cases (evals/cases.json), and 140 have a worked example in examples/.
  • Measured scores: 28 skills have blind-judged scores on the leaderboard (average 4.4/5 across the models tested); the benchmark report publishes the negative findings too. Everything unscored is unscored, not assumed good.
  • Human review: of the 154 skills rated high-stakes in risk tiers, 0 have a current review by a qualified professional. The expert-review programme and its ranked queue exist for exactly this; if you hold a relevant credential, reviewing one skill is the most valuable contribution available.
  • Reported savings: none recorded yet. Tell us what a skill saved you: hours and money only, added up in public on the Wall of Wins.
  • It rewrites itself, in public: the weakest skills are periodically rewritten by a model and kept only if a judge scores the rewrite higher; every attempt, including the losses, is in the evolution log.
  • Honesty rules baked in: decoders end with a not-advice line (the severity scale), calculators name what they do not model, simulators debrief out of character. PM Skills is not a substitute for a professional.

Privacy, stated plainly: everything installable runs locally. Skills are inert markdown on your machine; the CLI, the exports and the local MCP server send nothing anywhere, and telemetry is off unless you set PM_SKILLS_TELEMETRY=1 (skill name only, never content). The two things that do leave your machine are your prompts to whichever model provider you chose, and requests to the hosted playground or hosted MCP if you opt to use them. Full statements: docs/TELEMETRY.md · report a vulnerability: SECURITY.md · licence: MIT. Verify a release: npx pm-claude-skills verify --release (signed SBOM, Sigstore provenance).
