Learn while your agent works — and carry project context forward.

Named for Ekalavya, who mastered archery practicing before a silent statue of his guru. Here, the statue talks back.

Eklavya is a plugin for Claude Code. It does two jobs:

  1. It helps you understand the code Claude writes. It asks you short questions about the work, while the work happens.
  2. It remembers what happened in your project. The next time you open Claude, it can recall what you did last time.

Your learning history and memory are stored on your computer. There is no Eklavya account. Eklavya sends anonymous daily usage counts, never code, paths, names or text. Every field is listed, and eklavya telemetry off stops them. New installs use claude-sonnet-5 through your Claude Code login for memory summaries and prompt feedback, so captured session evidence goes to that model. Memory and data explains the controls.

Learning

Eklavya notices the ideas behind Claude's work, like "database index" or "refresh token". Then it asks you about them.

What it does How it works Read more
Asks while you work One question at a time, in the middle of the task, written so you can answer without having read the code, and so the right option is not the longest, the most detailed or explained in advance, and does not always come first. Answer, say you don't know and get the explanation, or skip and move on; a question that was itself at fault never counts against you, and an automatic question is meant to stay one question. First session
Asks while agents build For a larger change, Eklavya asks Claude to hand the building to a background agent (in your task's worktree, one stage at a time for a staged plan) and ask you questions while it works. If Claude starts changing a second file itself, Eklavya reminds it once. The dials
Grades your answer Each answer gets a grade and a short explanation. Grading
Brings topics back Spaced reviews bring an idea back before you forget it. Grading
Grows with you Each project starts easy. Good answers unlock harder questions. Levels and tiers
Teaches a topic /eklavya:learn caching gives a short lesson, basics first. Commands
Quizzes on demand /eklavya:quiz asks about this session's work right now, or about a topic, domain or concepts you name. Commands
Adds new subjects Comes with git, Node backend, React and web auth. Add more with /eklavya:pack. Concept packs

Memory

Eklavya records what you and Claude do. It turns that into short notes called observations. When you start a new session, Claude gets recent, relevant notes to check against the code.

What it does How it works Read more
Captures your work Saves prompts, file edits and tool calls as you work; unattended claude -p runs keep only tool and file activity. What gets captured
Hides secrets Skips files like .env and keys, even when a read or edit of one fails. Removes tokens and passwords before saving or trimming. What is never captured
Writes summaries Groups work into observations and session summaries, using claude-sonnet-5 on a new install or your saved observer choice. How observations are made
Recalls history Gives Claude past work and where the last session left off at session start, on related prompts, and before it reads a file with history. On prompts and on a resume it skips entries the current session wrote, which Claude already has. The session banner shows the estimated context saved. How recall works
Search and notes Ask /eklavya:memory about a past change, save a note or fix a wrong entry. Commands
Shows the savings Estimates how much smaller recall is than the raw history, counting recall a hook sent. Calls to the memory search and read tools are logged locally. Savings
Imports Claude Mem Brings in your history from Claude Mem, up to its schema version 64. Migrating
Syncs machines Optional: share memory between your computers through a folder. Files that arrive late are still applied. Sync

Memory is only evidence. It never marks a topic as learned. Only a real answer does that.

Dashboard

Run eklavya dashboard to open a local page in your browser. It keeps running in the background, and each session start restarts it if needed. The sidebar's foot shows the version it is running, with links to the docs. A malformed request gets an error reply instead of stopping it. A page left open shows new activity as it happens, including a session summary rewritten in place, and never moves what you are reading. You can also install it as an app and open it from Spotlight, the Dock or the Start menu. On your first visits, tips point out features; dismiss them one by one or switch them off under Settings, then Companion. The archer companion smiles while loading and appears beside empty states and feedback; the same tab previews its expressions and motion and has the daily card switch. On a wide window each page sits centred beside the sidebar. It has five parts:

Learning Accuracy, mastery, missed answers still to be corrected, your streak and its calendar, with the archer beside it and one card the first time you open the page each day, reviews due with a command per project to start them, the top three shown (each run asks the weakest first), weak topics, sessions and projects, each project at its own level. Learning pages

The dials

Each setting works on its own. Memory has its own switch, so you can turn questions off and keep memory on.

Dial Default Other choices
quiz.enabled true: ask questions false: no questions
quiz.enforced false: commit freely true: pass a quiz before a commit
quiz.panel true: experimental side panel on supported Claude Code builds false: Claude's question card. Cowork and unsupported hosts use the card.
focus concept: the idea behind the code project: this codebase · learn: a topic you pick
feedback.enabled true: review one of your prompts using what you had to add later false: no prompt review. Needs memory and an observer model.
cadence as-you-go: during the task end: after the task
difficulty auto: grows with you easy, medium or hard
memory.enabled true: record and recall false: learning only

By default Eklavya asks only in sessions that change code (edit tools or shell commands, in this checkout or a sibling worktree), up to four questions per session on its own. Checkpoint questions are at least four minutes apart; questions while background agents build share the budget but skip that gap. /eklavya:quiz can always ask more. Change a dial with /eklavya:mode in Claude Code, eklavya config set in a terminal (eklavya config get quiz.enabled reads one back), or the dashboard's Settings pages. quiz.panel can be changed with eklavya config set quiz.panel false or in Settings; a round you ask for with /eklavya:quiz keeps its topic and length across the panel's Next button, and a miss in the panel starts its explainer page in the background (and so does its orange New to me — Teach me button, which records "I don't know" even with explain_on_wrong off), asking once more and queuing a prompt for Claude only if Claude Code refuses or fails that start twice. A picked answer gets bold text, a thicker border and a filled background, and a press on its note picks it too; on the desktop app a long option wraps instead of being cut off. In the panel's Other box, Enter keeps what you typed and moves the keyboard to Submit answer. A prompt the panel sends Claude shows in your transcript as one short line. If Claude Code's auto mode denies the panel's tools, allow them as the manual shows, or ask Claude to. See the dials and every setting.

Commands

Command What it does
/eklavya:quiz [topic] Take a quiz now.
/eklavya:mode [value] Show or change the dials.
/eklavya:skip Skip questions for this session only.
/eklavya:learn <topic> Take a short lesson.
/eklavya:level [level] See your level or pick one.
/eklavya:pack [topic] Add new topics, or topics from your code.
/eklavya:progress See what you know and what is due.
/eklavya:memory Search past work or save a note.
/eklavya:gate See why a commit is blocked.
/eklavya:setup Check the installation without changing settings.

You can also just ask, like "Space out Eklavya's questions". See all commands and the CLI.

Install

With Claude Code and Node.js 22+ with npm on macOS, Linux or Windows:

npm install -g eklavya && eklavya install

The installer uses the defaults without asking settings questions and keeps any choices you already saved. Allow the side-panel tools in auto mode, then restart Claude Code and start a task. Eklavya updates itself in the background. See Installation options for other setups.
