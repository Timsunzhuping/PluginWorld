宣传片

3 分钟看懂 DeepSeekBot：一组有身份、人格和记忆的 bots，在小镇里一起做事。点击封面即可播放。

DeepSeekBot（简称 DSB，是 DeepSeekBot 的缩写，才不是“大啥比”，哼）是 BotHarness 开发的 MIT 开源 GrokBot 平替，作为插件运行在 DeepSeek Harness（DSH）里。你可以创建几个分别负责研究、写作或写代码的 Bot，像和同事一样私聊、拉群、派活；它们记得你，会按时做事，还能在 Slack、Discord、飞书 / Lark、QQ 和微信里以自己的身份回你消息。

模型用你在 DSH 里配置的服务商和额度；Bot 需要在后台持续工作时，运行 DSH 的电脑要保持在线。它和名字很像的 DS Bot（npm ds-bot）是两个独立项目，区别见下文。

安装

在 DeepSeek Harness 桌面端点「插件 → 添加插件」，输入 deepseekbot@1.2.1，安装并启用，侧栏就会出现「Bot 模式」。还没装 DSH？先下载桌面端。

命令行安装、版本说明和常见问题见官网安装指南。

能用它做什么

你想要 DeepSeekBot 怎么帮你
一支自己的 AI 小团队 创建研究员、设计师、工程师等 Bot，每个都有名字、人格和像素头像，换个对话也还是同一个它。
让 Bot 记住你 Bot 会记下你的偏好和项目背景，下次直接接着干；记忆随时能翻看、纠正，也能同步到别的电脑。
多个 Bot 一起干活 把 Bot 拉进群聊，需要谁就 @ 谁；大一点的任务可以交给 Bot 单独去做，做完交回报告，需要你拍板时会提醒你。
在常用的聊天软件里找它 把 Bot 接入 Slack、Discord、飞书 / Lark、QQ 和微信，在群里 @ 它或私聊，它就在原处用自己的身份回复；微信私聊里还能收发文件。
定时做事 说一句「每天早上 9 点给我发日志摘要」，Bot 就自己建好定时任务；也可以手动设置每隔几分钟、几小时或每天执行。
帮你操作电脑和浏览器 授权后，Bot 可以打开网页、点击、输入、截图，或操作一台共享桌面；你能实时看着它做，随时暂停。
一键装别人做好的 Bot 在 Bot 市场浏览、安装别人分享的 Bot，也能把自己的 Bot 分享出去，或打包成 zip 发给朋友。
知道每次更新了什么 升级后会告诉你这一版新增了什么；在设置里就能检查并一键更新。

每个 Bot 的记忆就是一个普通的 Git 仓库。你可以在侧栏翻看它记了什么、哪天改了哪几行，觉得不对就直接改；推到 GitHub，就能在几台电脑之间共用同一个 Bot。详见记忆演化指南。

DeepSeekBot（DSB）与 DS Bot（ds-bot）：两个项目，不同重心

名字很像，但这是两个独立的开源项目：都运行在 DeepSeek Harness（DSH）上，都不是 DeepSeek 公司官方产品。

  • DeepSeekBot（DSB），即本仓库，由 BotHarness 维护：让每个 Bot 成为一位能走出 DSH 窗口的长期同事。重心是可审阅的 Git 记忆、Bot 自己的飞书 / Slack / Discord / 微信身份、定时任务、任务委派和 Bot 市场。
  • DS Bot，即 Fei2411/DeepSeek-Bot（npm ds-bot，项目 README 中也写作 DeepSeek Bot）：把 DSH 本身变成一个 Bot 聊天应用。重心是由主 Bot「Chief」通过对话带你建好团队、群管理员默认统筹回复以控制 token 消耗，以及按时间、Bot 和模型查看用量。

怎么选：想让 Bot 在 IM 里以自己的身份工作、想用 Git 审阅和同步记忆，试试 DeepSeekBot；想在 DSH 里由主 Bot 一步步带着建团队、关注 token 用量，试试 DS Bot。两者都开源，欢迎都去读读源码：DeepSeekBot · DS Bot。更详细的对比见官网文章。

常见问题

这是哪个 DeepSeek Bot 项目？

这里是 BotHarness 的 DeepSeekBot（DSB）：安装包为 deepseekbot，官网为 deepseekbot.app。DS Bot 使用 ds-bot，是另一个独立项目，不是本产品的简称或旧版本，区别见上文。

DeepSeekBot 只能使用 DeepSeek 模型吗？

不是。它使用 DSH 中配置的模型提供商；能否接入取决于接口支持、模型配置与凭据。Bot 的记忆和聊天记录保存在自己的宿主，调用远程模型时相关上下文仍会发给所选服务商。
