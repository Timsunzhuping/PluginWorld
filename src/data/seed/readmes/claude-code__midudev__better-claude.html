better-claude

Plugins and mods for Claude Code by midudev, one per folder in plugins/:

Plugin What it does Folder
Image Preview Hover a pasted [Image #N] to see the picture, while you write and on the prompts you sent. plugins/image-preview/
Sub Meter Subscription usage at the bottom right: the 5-hour and weekly windows, as a bar. plugins/sub-meter/
Commit /commit asks commit + push, commit only or a new branch, then splits your changes into Conventional Commits, on Haiku 5.5. plugins/commit/

Install

/plugin marketplace add midudev/better-claude
/plugin install image-preview@better-claude
/plugin install sub-meter@better-claude
/plugin install commit@better-claude

This repository is the marketplace: .claude-plugin/marketplace.json lists each plugin folder as a source.

Development

Each plugin is its own folder with its own manifest. One package.json at the root runs everything: npm test, npm run validate, npm run test:node (After's unit tests) and npm run test:mod (every plugin's tests against the engine).
