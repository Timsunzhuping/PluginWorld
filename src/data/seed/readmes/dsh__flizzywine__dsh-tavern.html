DSH Tavern

基于 DSH（DeepSeek Harness）的 Agent 酒馆。兼容 SillyTavern 生态，人物卡导入就能玩。

更快 · 更稳 · 更鲜活 · 所有模型都能用 · 手机也能玩

下载安装 · 使用文档 · 宣传视频 · 讨论区 · Discord 交流群

  • 兼容 SillyTavern 生态：人物卡、世界书、预设、正则美化、MVU、酒馆助手脚本，导入就能用。
  • 更快：一轮约 10 秒，缓存命中率 95% 以上。
  • 更稳：状态栏不再掉格式。变量由后台按规则结算，每轮附更新结果，失败可单独重试；更新与重装都保留数据。
  • 更鲜活：同样的模型、同样的预设，比原版酒馆更有活人感。因为前台模型只管写正文，变量结算等任务性工作交给后台模型。
  • 手机也能玩：Android 手机直接安装；电脑上运行的酒馆，手机扫码就能远程游玩。

工作方式 ❌ 一口气：一个模型在一次请求里完成所有事 ✅ 分步：正文、变量结算、候选项各自完成
出错重来 ❌ 整轮重新生成，满意的部分也一起丢掉 ✅ 哪步出错重来哪步，正文和候选还能附上指导意见
正文 ❌ 写正文的同时要记住各种格式要求，注意力被分散 ✅ 前台专心写正文
状态栏 ❌ 每一轮都要求模型重新输出状态栏，写长了容易掉格式 ✅ 状态栏固化：MVU 版由固定模板按变量显示，不再由模型输出，绝对不会掉格式
候选项 ❌ 写正文的同时还要兼顾生成候选项，注意力涣散，还可能掉格式 ✅ 和正文任务拆分，专注生成候选项；通过工具提交并校验，显示在固定面板，绝对不会掉格式

② 注入 Guide，临时规划剧情走向
③ 候选项自动规划下一步，避免剧情停滞
记忆 ❌ 靠压缩总结提前猜测需要什么记忆，提前注入，难以预测真实需求 ✅ 内置记忆检索工具，需要什么记忆，Agent 自行检索原文
缓存与速度 ❌ 未考虑缓存利用：世界书条目内容一变化，缓存就失效 ✅ 缓存命中率 95% 以上，一轮约 10 秒
写作方法 ❌ 写进预设，每轮常驻提示词 ✅ 写成 Skill，按场景调用
边玩边改卡 ❌ 想排错或按喜好调整，都要自己翻人物卡、世界书、正则，逐项手改 ✅ 边玩边改：
① 排查错误：有问题随时交给调试 Agent，结合实际游玩记录分析并修复
② 调整内容：用对话告诉 Agent 哪里不喜欢，按自己的口味微调

⚠️ 不支持安装酒馆插件（DSH 插件可以装），但内置了酒馆助手、MVU、提示词模板等重要插件，足以支撑大部分人物卡

产品特色

剧本模式

导入小说、剧本或大纲，绑定到人物卡，就能走进原作亲历主线。剧本定方向和关键事件，你决定人物怎么走到那里，随时可以偏离。剧本按片段读取，再长的小说也不用整本塞进上下文。了解更多 →

长期记忆

每轮正文完整保存，Agent 需要时自己回查原文，不靠摘要硬记；配合上下文压缩，玩到几百层仍能记起开局的细节。了解更多 →

对话式修改人物卡

不用懂卡片字段，告诉 Agent 哪里不喜欢、想改成什么样，它先给方案，你确认后才写入。也能从小说里提取人物做新卡，或用同样方式修改世界书和预设。了解更多 →

人物卡转 MVU 版，状态栏不再掉格式

正文里的状态栏老是掉格式？让 Agent 把人物卡转成 MVU 版：前台只写正文，变量由后台按规则结算，状态栏常驻右侧，原卡图片和设定都保留。了解更多 →

自助调试 Agent

正则没生效、美化显示不对、状态栏没更新？在右侧展开「遇到显示或生成问题？」，点「交给卡片 Agent 调试」，Agent 会读取这局的实际游玩记录和日志，分析原因并修改相关资源，不用自己翻配置猜问题。了解更多 →

Guide：给这一局注入上下文指引

想要的写法、节奏或剧情走向写成一条 Guide，比如“多写心理活动，对白不超过三句”“好感度涨得慢一点”。它会注入上下文，之后每轮正文、候选和变量结算都会参考，不用每次重复。了解更多 →

带意见重写

不满意这轮回复，写上哪里要改，比如“保留事件，但减少旁白解释”，只重写这一轮，比反复抽卡更可控。了解更多 →

后台人物设计

重要人物登场时，后台为其设计完整档案：动机、性格、外貌、说话方式、与主角的关系，之后反复出场都按同一套设定来，不会前后走样。已有设定直接复用，不重复造人。了解更多 →

写作 Skill

把写作教程或喜欢的样文交给 Agent，提炼成场景写作 Skill，比如打斗、悬疑、感情戏各有一套写法；游玩时模型按场景自动选用。了解更多 →

支持插件生态

插件分两类：

DSH 插件：酒馆运行在 DSH 上，可以直接安装其他 DSH 插件一起使用，例如手机访问的 dsh-pocket、远程登录认证的 dsh-webui-auth、语音朗读插件等。缺什么能力，也可以让 Agent 帮你写一个自定义工具。了解更多 →

DSH Tavern 专属插件：为酒馆游玩专门开发的插件。社区已有：

插件 作用
dsh-tavern-image 剧情自动配图，支持 ComfyUI、NovelAI、Gemini 等多平台，带人物库
dsh-card-updater 卡片更新器，作者发布新版时提醒你
dsh-wrongbook 错题库，按人物卡记下调试踩过的坑
动态世界书生成 后台结算时生成世界书条目

以上均为社区作者开发，更多插件见讨论区的 Show and tell。

安装酒馆插件：设置 → DSH Tavern → 插件，粘贴插件的 GitHub 地址，点「安装」，刷新页面即可；有新版时显示「更新到 x.y.z」，更新后重启 DSH 生效；也可以随时「停用」或「启用」插件；连不上 GitHub 时，下载插件 ZIP 后在同一处上传。插件作者见发布与一键安装。

快速开始

当前版本适配 DSH 0.2.1。还在用 DSH 0.1.5（DSH Desktop 2.0.13、旧一键安装包）的，请用稳定版。安装前建议备份 .dsh 目录。

Windows

  1. 安装 DeepSeek Harness 0.2.1-rc.2（或社区版 DSH NEXT），打开一次后从托盘退出。

  2. 安装酒馆，以下两种方式任选其一：

    • 方式 A：双击安装。下载安装程序，双击运行（安全提示点「更多信息 → 仍要运行」）。

    • 方式 B：命令安装。打开 PowerShell，粘贴下面这行并按回车执行：

      $env:DSH_TAVERN_HOST='desktop'; $tavernInstaller=[Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://raw.githubusercontent.com/flizzywine/dsh-tavern/main/install.ps1')); Invoke-Expression $tavernInstaller

  3. 重新打开 DeepSeek Harness，即进入酒馆。

Android

首选 独立 APK（Android 11+ / ARM64）：下载 DSH Tavern Android APK。它内置 DSHA v0.2.0-rc2 与 DSH 0.2.0-rc.2，只运行酒馆自己的 tavern Profile，手机上只有一个 DSH 服务，内存和电量开销最低。首次按引导完成环境部署后自动安装并进入；酒馆更新在应用内完成。包名独立，可与旧版 v2.1 APK、原版 DSHA 并存，旧包数据需先导出再导入。详见 Android 安装说明。

设备不满足 APK 要求时，可以改用 DSHA v0.2.0-rc2 + 安装脚本：

  1. 安装 DSHA v0.2.0-rc2，打开一次。

  2. 打开底部 终端，粘贴下面这行并按回车执行：

    curl -fsSL 'https://raw.githubusercontent.com/flizzywine/dsh-tavern/main/android/setup.sh' -o /tmp/dsh-tavern-setup.sh && bash /tmp/dsh-tavern-setup.sh

  3. 看到 全部完成 后重启 DSHA，点 启动 → 进入 → 酒馆工作台。

这条路线会同时运行 DSHA 和酒馆两个 DSH 服务，内存、耗电和 CPU 占用都高于独立 APK。

macOS

  1. 安装 DeepSeek Harness 0.2.1-rc.2，打开一次后退出（⌘Q）。

  2. 打开「终端」，粘贴下面这行并按回车执行：

    curl -fsSL 'https://raw.githubusercontent.com/flizzywine/dsh-tavern/main/install.sh' -o /tmp/dsh-tavern-install.sh && DSH_TAVERN_HOST=desktop sh /tmp/dsh-tavern-install.sh

  3. 重新打开 DeepSeek Harness，即进入酒馆。

命令行版（Windows / macOS / Linux，用浏览器玩）

不需要桌面版。命令行版自带一套独立的 DSH，和程序、游戏数据一起装在自己的目录里（默认 ~/.dsh-tavern），不会改动、也不会和你已经装好的 DSH 冲突：桌面版、全局的 dsh 命令照常使用，两边互不影响，可以同时运行。需要 Node.js 22.19+ 和 pnpm。

Windows（PowerShell）：

$env:DSH_TAVERN_HOST='cli'; $tavernInstaller=[Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://raw.githubusercontent.com/flizzywine/dsh-tavern/main/install.ps1')); Invoke-Expression $tavernInstaller

macOS / Linux：

curl -fsSL 'https://raw.githubusercontent.com/flizzywine/dsh-tavern/main/install.sh' -o /tmp/dsh-tavern-install.sh && DSH_TAVERN_HOST=cli sh /tmp/dsh-tavern-install.sh

装好后用 dsh-tavern start 启动，按显示的地址在浏览器打开；dsh-tavern stop / status / update 停止、查看、更新。

手机远程访问

酒馆跑在电脑或服务器上，用手机浏览器也能玩。详细说明 →

  • 电脑运行、手机扫码：安装 dsh-pocket，在 设置 → 手机访问 选择局域网或公网，扫码即可。
  • 服务器部署、账号登录：安装 dsh-webui-auth，为远程网页加上登录认证。

在 设置 → 模型 填入模型服务和 API 密钥（任意模型都可以，本地模型也行），导入人物卡就能开局。图文教程 →

更新、旧存档与切回原版

  • 在酒馆里点「检查更新」即可更新，也可以重新运行上面的安装命令；只替换程序，人物卡、聊天和设置都会保留。
  • 旧版本的存档：打开后在「酒馆状态」里点「迁移存档」。正文、变量、分支和历史版本都会保留。迁移后的数据目录不要再让旧宿主直接读取。
  • 桌面版切回原版 DSH：设置 → 原版DSH → 切到原版 DSH 并重启。之后在原版 DSH 的设置 → DSH酒馆，就能切回酒馆。不要删除 .dsh/backups 和 profiles/desktop.fresh-*。细节见桥接插件说明。
  • 旧酒馆在自定义目录、需要继承数据时，见数据继承说明。

稳定版（DSH 0.1.5）

适配 DSH 0.1.5-rc.2（DSH Desktop 2.0.13、DSHA 0.1.5-rc2），在 stable 分支维护，只修严重问题。安装方法（含一键安装包）见 稳定版 README。

已经装了稳定版、点更新时提示「DSH 版本不符」的：要继续用 DSH 0.1.5，按稳定版 README 重新运行一次安装命令，以后的更新就跟随稳定版；要换到当前版本，先装上适配的宿主再更新。
