CodeBee

把多个 AI 编码 CLI 编排成协作团队。

快速开始 → QUICKSTART.md

最新版更新内容

  • 章稿引号制式双向自愈：写盘归一+读侧就地治愈，体例 major 不再复发
  • 多账号发布体系：账号登记/切换/断开，书籍按账号路由
  • 番茄今天直发模式；七猫建书改版全通
  • 确定性失败分类、ACP 原子写入、日志降噪

它解决什么问题

开发者装了多个 AI 编码 CLI，但它们往往彼此孤立。CodeBee 把这些 CLI 统一接入， 按任务路由、执行、验证、评审并在需要时自动修复，最后生成可审计的报告。

核心特性

  • 跨厂商 CLI 统一调度：Codex CLI、Claude Code、OpenCode、QwenCode、Aider、Kimi Code、 MiMo Code、Grok Build、Pi、DeepSeek Harness、Gemini CLI、CodeBuddy CLI、Trae Agent、 MiniMax Code、Mistral Vibe、Cline CLI、OpenClaw（Goose 与 GitHub Copilot CLI 当前仅检测）。
  • 智能路由与跨厂商降级。
  • 对抗式评审：评审者优先来自不同模型族。
  • 短剧剧本工作流：项目圣经、分集大纲、逐场剧本与双评审；当前交付文本，不生成视频。
  • 本地运行，隐私优先，运行时零第三方 Python 依赖。
  • 全程落盘，可回放任务、步骤、日志和报告。

和同类工具的差异

维度 CodeBee Aider 其他 agent 框架
多 CLI 支持 原生多 CLI 目录与适配器 以单一 CLI 为主 取决于框架
跨厂商评审 内置模型族隔离与降级 需自行组合 通常需自行实现
零运行时依赖 Python 标准库 需要 Python 依赖 取决于实现
本地优先 默认本机 Web UI 与本地数据 本地运行 取决于部署方式
Web UI 内置本地 Web UI 以终端工作流为主 取决于框架

本地 Web UI 安全说明

本地 Web UI 默认仅监听 127.0.0.1，不会暴露到局域网。如需从其他设备访问，请自行评估安全风险，并显式传入 --host 0.0.0.0，同时配置令牌、反向代理或其他访问控制。

源码启动：

python app\main.py --port 8765

默认打开 http://127.0.0.1:8765。需要局域网访问时：

python app\main.py --host 0.0.0.0 --port 8765
