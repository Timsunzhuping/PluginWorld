SAIFS AI — MCP servers

Hosted Model Context Protocol servers from SAIFS AI for sales, inventory, marketing, HR, education, logistics, collections, procurement, media generation and travel. Every server is remote (Streamable HTTP) with OAuth 2.1 sign-in, so there is nothing to install — add the URL to any MCP client.

All servers are published in the official MCP Registry under the DNS-verified ai.saifs namespace.

Inventory Intelligence & Optimizer ai.saifs/inventory-intelligence-optimizer Work out what to order, when to reorder, what is overstocked and how much cash is tied up in stock.

Hiring Fairness & Selection ROI ai.saifs/hiring-fairness Detect hiring adverse impact and estimate whether a selection method is worth its cost.

Quick start

  1. Open the folder for the server you want and copy its URL.
  2. Add it to your client — VS Code / Copilot (mcp.json), Claude (Settings → Connectors), Claude Code, Cursor or any MCP client.
  3. Sign in when the client prompts you.

Each folder's README has client-specific config, the tool list and example prompts.

This repository

This repo holds the public listing for each server: README, server.json (the registry manifest) and install config. The servers themselves are hosted by SAIFS AI. New versions are published to the official MCP Registry by .github/workflows/publish-mcp.yml.
