AgentMart plugin

AgentMart (https://agentmart.ciphyr.ai), run by Ciphyr Tech OÜ in Estonia, hosts the parts of an AI agent's work that need a server that stays on after the session ends: always-on utilities (webhook inbox, memory locker, wake-up calls, share link, uptime watch, form inbox, ask my human, heartbeat monitor, owner reminders, durable queue, Project Blueprint), mail tools (an email list check that finds addresses that would bounce, a sender health check of a domain's email DNS, and a hosted unsubscribe list) and tested TypeScript code kits (among them email campaigns and invitations). Items are paid from a prepaid balance that the human tops up on Stripe's page; the agent asks the human before every purchase (or follows a standing rule the human set).

This repository is one plugin for many coding agents. It connects the AgentMart MCP server and adds two skills:

  • check-the-shelf: when a task needs one of the always-on parts above and nothing the user already has covers it, compare a ready part with building it and with free options, then let the human choose.
  • agentmart-buying-rules: sign in safely, get funds only through the human, and buy only with the human's clear yes.

When not to use it

  • For the user's own product code, or when they asked you to build the part yourself.
  • When the project already has a service for it (a queue, a scheduler, an inbox).
  • When a free local option is enough for the task.

Sign in

Your app signs in with OAuth on AgentMart's approval page (one click, no password), so no token appears in the chat. In Claude Code: type /mcp, pick plugin:agentmart:agentmart, choose Authenticate. In Gemini CLI: /mcp auth agentmart. An approval alone gives the app an empty passport; to use an account's balance, the owner gets a one-time code on the Add an AI app page of agentmart.ciphyr.ai and pastes it on the approval page. Searching and reading the catalog need no sign-in.

What it runs, sends and fetches

  • No local code, no hooks, no scripts, no rules that write to your files.
  • One remote MCP server: https://agentmart.ciphyr.ai/mcp. Your client talks to it directly.
  • Whatever the agent sends to AgentMart's tools (search words, items it stores in a utility, messages it schedules) goes to AgentMart's servers. Privacy notice: https://agentmart.ciphyr.ai/privacy. Terms: https://agentmart.ciphyr.ai/terms.
  • Nothing is bought without a tool call that your client shows you, and the skills tell the agent to ask you first. Prices are never written here: the agent reads them from the catalog.
