What is Claude Code?

A command-line tool from Anthropic. You describe what you want, and it reads your files, writes and edits code, runs commands, and tells you what it's doing along the way.

Official repo and docs: github.com/anthropics/claude-code

Quick start

macOS / Linux:

curl -fsSL https://claude.ai/install.sh | bash

Windows (PowerShell):

irm https://claude.ai/install.ps1 | iex

Then:

mkdir my-project && cd my-project
claude

You'll need a Claude Pro/Max subscription or an Anthropic API key. On first launch it opens a browser to log in, or you can set ANTHROPIC_API_KEY. If anything goes wrong, Module 1 walks through installation on every platform.
