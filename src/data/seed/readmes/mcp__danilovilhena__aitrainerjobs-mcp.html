AI Trainer Jobs MCP server

Find remote AI trainer jobs and compare the companies that hire for them, from any AI assistant.
Free, read-only, no account, no API key.

https://aitrainerjobs.co/mcp

AI Trainer Jobs lists open, remote, paid jobs that train and test AI models: coding, STEM, medicine, law, finance, languages, creative work, and more. The jobs come from public job posts on each company's own job board, such as micro1, Mercor, DataAnnotation, Prolific, and xAI, and the list updates every 5 minutes.

This repository documents the hosted MCP server. There is nothing to install or run: connect your client to the URL above.

Connect

Client How

Any other client Add a remote MCP server with Streamable HTTP and the URL above. No auth.

JSON config, for clients that use one:

{
  "mcpServers": {
    "aitrainerjobs": { "type": "http", "url": "https://aitrainerjobs.co/mcp" }
  }
}

Tools

All tools are read-only.

Tool What it does Inputs
search_jobs Open jobs, newest first, with pay, location, a short summary, the job page, and the apply link query (title, company, or skill), category, min_hourly_pay (USD), pay_type (hour, task, once), eligible_country (ISO code), limit (1 to 20), offset
get_job One job: requirements, what the work is, languages, level, hours, and the company's full description id
list_companies Every company with open jobs, median pay, typical pay, worker rating, and how it pays none
get_company One company: what it does, how and when it pays, the hiring steps, and what workers say name

Categories: coding, stem, medical, legal, finance, languages, voice-video, creative, generalist, robotics.

Example prompts

  • "Find remote AI training jobs for nurses that accept people in Brazil."
  • "Which AI training companies pay the most per hour, and how do they pay?"
  • "Is Prolific legit? How does it pay, and what do workers say?"
  • "Show me Spanish-language AI tutor jobs that pay at least $30 an hour."
  • "Compare Mercor and micro1 for a software engineer."

Details

  • Transport: Streamable HTTP, stateless. Supports MCP 2026-07-28 and older clients that send initialize.
  • Auth: none.
  • Rate limit: 600 requests per minute per client IP. Over the limit, the server answers HTTP 429 with Retry-After.
  • Server card: /.well-known/mcp/server-card.json
  • Registry: co.aitrainerjobs/jobs in the official MCP Registry.
  • REST API: the same data as JSON at /api/v1, with an OpenAPI spec.
