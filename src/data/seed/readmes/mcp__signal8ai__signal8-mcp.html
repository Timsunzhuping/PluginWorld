@signal8ai/mcp

MCP (Model Context Protocol) server for Signal8 -- AI-extracted SEC filing intelligence data.

Gives AI agents like Claude, Cursor, and other MCP-compatible tools direct access to:

  • Company fundamentals (quotes, financials, earnings, float, executives, peers, news)
  • Dilution analysis (warrants, convertibles, preferred, shelf registrations, ATMs, equity lines and S-1 offerings, each figure cited to the SEC filing it was read from)
  • Dilution Pressure Score (0-100, seven components: shelf capacity, ATM/equity-line capacity, warrants in the money, convertible proximity, cash burn, historical dilution, toxic financing)
  • Baby shelf capacity (S-3 General Instruction I.B.6 one-third-of-float cap, recomputed from the live float)
  • Cash runway (cash position, monthly burn, capital raises since the last balance sheet)
  • Intelligence (counterparties, counsel, insiders, institutions, ROFR triggers, cluster buys)
  • Cross-company intelligence (top AUM institutions, cross-company counsel & insider patterns)
  • Compliance monitoring (Nasdaq/NYSE deficiency detection, listing classification)
  • Company screening (dilution-aware filters with 30+ fields)
  • ETF analysis (holdings, sectors, countries, performance, comparables)

Installation

npm install -g @signal8ai/mcp
# or use npx (no install needed)
npx @signal8ai/mcp

Setup

1. Get your API key

API and MCP access are included with Signal8 Pro ($59/mo, or $588/yr). A free Signal8 account cannot create API keys. Upgrade at signal8.ai/pro, then create a key in the developer portal at signal8.ai/developer/api-keys.

Using Claude.ai or Claude Desktop? You can skip the key entirely: add the hosted server as a custom connector and sign in with your Signal8 account (see Hosted Endpoint).

2. Configure your MCP client

Claude Desktop

Add to your Claude Desktop config file:

macOS: ~/Library/Application Support/Claude/claude_desktop_config.json Windows: %APPDATA%\Claude\claude_desktop_config.json

{
  "mcpServers": {
    "signal8": {
      "command": "npx",
      "args": ["-y", "@signal8ai/mcp"],
      "env": {
        "SIGNAL8_API_KEY": "sk_live_your_key_here"
      }
    }
  }
}

Cursor

Add to .cursor/mcp.json in your project root:

{
  "mcpServers": {
    "signal8": {
      "command": "npx",
      "args": ["-y", "@signal8ai/mcp"],
      "env": {
        "SIGNAL8_API_KEY": "sk_live_your_key_here"
      }
    }
  }
}

Other MCP Clients

Set the SIGNAL8_API_KEY environment variable and run:

SIGNAL8_API_KEY=sk_live_your_key_here npx @signal8ai/mcp

SEC Filings & EDGAR archive (10 tools)

Backed by Signal8's own archive of SEC EDGAR filings — the archive's held range (see archiveFrom in each response; currently from late 2021, expanding back to 2016 as the history backfill fills in), full-text indexed and updated through the day. Filings older than archiveFrom may be absent, so an empty result is not proof a filing was never made. Record-only rows (bodyStored: false) carry metadata but no body.

Tool Description
search_sec_filings Filings by CIK, form, date, 8-K items, excluded forms, full-text q (match exact/stemmed, sort newest/relevance, facets counts by form/year/8-K item, understand on/off, section search, exhibitTypes — see query syntax below), and company filters (market cap, float, price, sector, industry, exchange, company type, foreign issuer, recent IPO)
get_filing_documents Every document in a filing (type, size, stored, secUrl) with the filingId / exhibitId to read each one
get_filing_structured Parsed Form 3/4/5 transactions, 13F holdings (values normalised to dollars), XML SCHEDULE 13D/G
get_filing_document Full text of a filing by filing id
get_filing_exhibits Readable exhibits of a filing, with ids
get_exhibit_content Full text of one exhibit
search_filing_text Exhibit-level full-text search returning the matching passage (match exact/stemmed, sort, section, exhibitTypes)
lookup_accession_number Accession number → filing id and metadata
screen_sec_filings Filings across companies by sector / industry / exchange / market cap
screen_sec_filings_performance Price returns +1/+3/+7/+30 days after filings, with aggregates

Full-text query syntax (search_sec_filings.q, search_filing_text.pattern): unquoted words must all appear; "quoted phrase" for exact wording; OR between alternatives; -word to exclude; w1 NEAR/10 w2 (or NEAR(10), bare NEAR = 10) for proximity; word* for a prefix of 4+ letters; $AAPL or a capitalised ticker scopes to that company; a form code (8-K), item 5.02 / 8-K 1.05 and a bare year scope to that form / 8-K item / year. Relevance page 1 shows a few filings per company; meta.diversity names who has more. How the archive read the query is returned in meta.understanding (pass understand: false to search the words literally). facets: true adds per-form / per-year / per-8-K-item counts over the whole result set — absent when not measured, never zero.

Section search + exhibit types (both search tools): section restricts matching to business, risk_factors, cybersecurity, legal_proceedings, mdna, market_risk, controls, ex99 (press releases) or an 8-K item (item_5_02); exhibitTypes keeps filings with e.g. EX-10 (material contracts) or EX-99.1. A section is applied only when meta.sections says so — otherwise meta.unsupported explains that the whole filing was searched. Rows may carry matchedSections (absent = not measured).

Company filters on search_sec_filings follow the same rules as the signal8.ai/sec-filings page: they are applied from the archive only, against the filer's own CIK, on issuer-filed forms only (Form 4, 144 and SCHEDULE 13D/G are dropped and reported in companyFilter.droppedForms). Companies with no measured value for a filter are excluded and counted in companyFilter.unknown. Unknown values return a 400 listing the valid names. If the archive cannot answer, the call fails with COMPANY_FILTER_NOT_APPLIED and a reason rather than returning unfiltered rows.

13F values: the SEC changed the unit of a 13F <value> from thousands of dollars to whole dollars for filings on/after 2023-01-03. get_filing_structured returns valueUsd / totalMarketValueUsd normalised to dollars (null when the unit cannot be determined) next to the raw valueThousands, and valueUnit says which unit the raw number is in.

Dilution (7 tools)

Small-cap dilution analysis read directly from SEC filings. Every figure carries the accession number, filing date and the quoted sentence it came from. Included in Signal8 Pro. Call get_dilution_coverage first: it is the cheapest way to learn whether there is anything to fetch.

Tool Description
get_dilution_coverage Whether a ticker has a dilution analysis, how fresh it is, and why not if it doesn't
get_dilution_risk Dilution Pressure Score with its seven-component breakdown and risk levels. A partial score is out of scoreMaxMeasured (never rescale to /100); overall/overheadSupply are floors ("at least") when levelsAreLowerBound is true
get_dilution_snapshot Potential new shares and % of shares outstanding, cash position and runway, float
get_dilution_instruments One instrument family's rows with per-field SEC citations (warrants, convertibles, preferred, shelfs, atms, elocs, s1_offerings, equity_plans, exchangeables, recent_offerings)
get_baby_shelf_capacity S-3 I.B.6 baby shelf: how much the issuer can raise off its shelf right now
get_dilution_performance How the stock traded after each past offering priced or closed
get_dilution_history Shares-outstanding and cash series with offering overlays

Not measured is not zero. A null, withheld or unavailable figure means Signal8 did not measure it. It never means the company has no warrants, no shelf or no dilution, and the tool descriptions tell the model so.

Use the explain_dilution prompt to walk a ticker's dilution picture in plain English.

Hosted Endpoint

For web-based MCP clients, use the hosted Streamable HTTP endpoint:

POST https://mcp.signal8.ai/mcp
Authorization: Bearer sk_live_your_key_here
Content-Type: application/json

Clients that support custom bearer-token headers (e.g. Claude Code CLI's --transport http connector, Cursor, and VS Code's MCP support) can send your API key as shown above.

Clients that support MCP OAuth need no key at all. In Claude.ai or Claude Desktop, open Settings → Connectors → Add custom connector, paste https://mcp.signal8.ai/mcp, and Claude opens a Signal8 sign-in to authorize the connection. The server advertises its authorization server at https://mcp.signal8.ai/.well-known/oauth-protected-resource (OAuth 2.1 with PKCE and dynamic client registration, issued by https://api.signal8.ai). OAuth connections are subject to the same Signal8 Pro requirement and rate limits as API keys.
