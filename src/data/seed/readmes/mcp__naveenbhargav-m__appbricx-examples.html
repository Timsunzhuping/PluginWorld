Appbricx examples and tools

Everything you need to build on Appbricx from your own machine: a complete example app, ten app templates, the Claude Code plugin, the CLI, a Cursor config and the HyperFrames templates behind our demo videos.

Your coding agent builds the app; Appbricx runs it: Postgres per project with separate dev and prod databases, per-role access enforced by the database, sign-in, workflows, realtime, in-app AI, payments, releases tested as every user, and one-click rollback.

Folder What it is
studio-bookings/ The app from the end-to-end tutorial: contract, custom screens, a server function and a workflow. Live at example-bookings.apps.appbricx.com.
templates/ The ten showcase apps as contracts you can apply: Tablefor, Kanbo, Atelier, Clinicly, Eventra, Learnly, Relay, Nook, Ledgerly and Stride.
blocks/ Features to drop into any app: organisations and teams, Stripe subscriptions, one-off payments, booking calendar, comments, notifications.
workflows/ Automations: welcome email, Slack on signup, booking confirmation and reminder, daily digest, overdue alerts, reply-deadline escalation, Stripe payment received.
components/ Reusable screen parts: trend chart, CSV export.
plugins/claude-code/ The Claude Code plugin and skill.
cli/ appbricx, the command-line tool: log in, check, apply, verify, deploy, run SQL, edit rows, take snapshots.
cursor/ MCP config for Cursor (browser sign-in or a token header).
gemini-extension.json Gemini CLI extension: gemini extensions install https://github.com/Naveenbhargav-m/appbricx-examples
registry/server.json The Appbricx entry for the official MCP Registry.
video/hyperframes/ HyperFrames compositions and scripts to record and render walkthroughs, reels, terminal replays and slides of your own app.

Connect your coding agent

# Claude Code: connect, then run /mcp → appbricx → Authenticate (opens your browser)
claude mcp add --transport http appbricx https://www.appbricx.com/api/mcp

# or install the plugin (adds the skill too)
/plugin marketplace add Naveenbhargav-m/appbricx-examples
/plugin install appbricx@appbricx

Then ask your agent to build something. Agents can also find these templates themselves with the search_templates, get_template and use_template tools, or browse them at https://www.appbricx.com/templates. The format is in TEMPLATE_FORMAT.md.

Use the CLI

git clone https://github.com/Naveenbhargav-m/appbricx-examples
cd appbricx-examples/cli && npm link     # puts `appbricx` on your PATH
appbricx login                           # opens your browser, click Authorize
appbricx create "My app" && appbricx apply ../templates/kanbo/app.json
