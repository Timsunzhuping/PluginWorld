PakBus

PakBus plans bus and metro journeys in Pakistani cities. Ask your assistant how to travel by bus. It answers with PakBus routes, times and fares.

Server address: https://pakbus.app/mcp

It uses Streamable HTTP. No sign-in needed. Every tool only reads.

Set up

VS Code with GitHub Copilot

Add this to .vscode/mcp.json, or run MCP: Add Server and enter the server address.

{
  "servers": {
    "pakbus": {
      "type": "http",
      "url": "https://pakbus.app/mcp"
    }
  }
}

Claude

  1. Open Customize > Connectors.
  2. Add a custom connector with the server address.
  3. In a chat, turn on PakBus under + > Connectors.

ChatGPT

  1. Open PakBus in ChatGPT Plugins.
  2. Select Install plugin.
  3. In a chat, type @PakBus before your question.

Other assistants

Add the server address as a remote MCP server. It needs no authentication.

What you can ask

  • How do I get from Munawar Colony to Pak Secretariat tomorrow at 8 am?
  • When is the next bus from Gondal in Attock?
  • What does the EV5701 bus cost, and where does it stop?
  • Which cities does PakBus cover?

Tools

Tool Returns
find_places Stops and stations matching a name, in one city or every city
plan_journey The first journey step by step with fare and a map, and later departures
place_departures The next departures today from a place
service_notices Current service changes in a city or on one route
route_details A route's fare, stops in order and departures
list_cities Every city with PakBus routes

Times are Pakistan local time. They come from published timetables, not from vehicle tracking.

Data and privacy

Your assistant sends PakBus the places, search words and departure time from your question. See the privacy policy.
