🚀 Universal Installation Guide (All IDEs & LLMs)

Supported Platforms: Google Antigravity (AGY), Claude Code, Cursor IDE, OpenAI Codex CLI, Windsurf, Trae, VSCode (Cline / Roo Code), Kimi, and Kiro.

Method 1: CLI (NPM Installation - Recommended)

The CLI automatically scaffolds the required master rules for your specific IDE.

npm i -g vibes-plug
vibes-plug init

Method 2: GitHub Installation (Direct via NPX / Git Clone - Always Latest)

You can install or execute VibesPlug directly from the GitHub repository using any of the following methods:

Option A: Instant Execution via NPX (No Local Clone Required) Run the installer directly from GitHub without cloning the repository:

# Run installer for all detected IDEs & platforms
npx github:roedyrustam/vibes-plug --all

# Or install globally from GitHub
npm install -g git+https://github.com/roedyrustam/vibes-plug.git
vibes-plug --all

Option B: Clone & Universal Multi-Platform Installer Clone the repository and run the built-in installer to auto-configure all your tools:

git clone https://github.com/roedyrustam/vibes-plug.git
cd vibes-plug
npm install

# Run installer across all detected platforms:
npm run install-all
# (or node scripts/install.js --all)

Option C: Direct Git Clone for Google Antigravity (AGY) Google Antigravity natively loads plugins from ~/.gemini/config/plugins/. Clone directly into your Antigravity plugins directory:

# macOS & Linux:
git clone https://github.com/roedyrustam/vibes-plug.git ~/.gemini/config/plugins/vibes-plug

# Windows (PowerShell):
git clone https://github.com/roedyrustam/vibes-plug.git "$HOME\.gemini\config\plugins\vibes-plug"

Option D: Targeted Per-Project Installation From your cloned vibes-plug directory, inject rules and skills into any specific project:

# For Claude Code (global + project):
node scripts/install.js --claude --project /path/to/my-project

# For Cursor IDE (project-specific):
node scripts/install.js --cursor --project /path/to/my-project

# For OpenAI Codex:
node scripts/install.js --codex --project /path/to/my-project

# For Windsurf, Trae, or VSCode (Cline):
cp .windsurfrules /path/to/my-project/
cp .traerules /path/to/my-project/
cp .clinerules /path/to/my-project/

Option E: Staying Updated via GitHub To pull the latest skills and superintelligence engine updates:

cd ~/.gemini/config/plugins/vibes-plug  # (or your cloned repository folder)
git pull origin main
npm test

Method 3: Platform-Specific Manual Configuration (ZIP Archive / Drop-in)

If you download the .zip archive, extract it and configure your IDE as follows:

  • Google Antigravity (AGY): Move the folder to ~/.gemini/config/plugins/vibes-plug.
  • Claude Code: Run vibes-plug --claude or copy CLAUDE.md and .claude/rules/ to your project root.
  • Cursor IDE: Run vibes-plug --cursor --project . or copy .cursorrules and .cursor/rules/ to your project root.
  • OpenAI Codex CLI: Run vibes-plug --codex or copy CODEX.md and .codex/rules/ to your project root.
  • Windsurf IDE: Copy .windsurfrules to your project root.
  • Trae IDE: Copy .traerules to your project root.
  • VSCode (Cline / Roo): Copy .clinerules to your project root.
  • Kimi / Kiro: Copy .kimirules or .kirorules to your project root.
