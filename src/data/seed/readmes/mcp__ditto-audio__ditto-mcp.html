ditto.audio MCP server

Text-to-speech for AI agents. Connect ditto.audio to Claude, ChatGPT, Cursor, VS Code, Codex or any Model Context Protocol client. Your agent can then browse voices and synthesize speech that comes back as short-lived download links, never as audio bytes in the chat.

Endpoint: https://mcp.ditto.audio (Streamable HTTP)

You sign in with your ditto.audio account the first time your client connects. There is no key to paste. Each connection appears under Account -> API keys as a connected app, draws on the same monthly allowance as your keys, and can be disconnected there.

Install

Client How
Claude (web, desktop, mobile, and Claude Code signed in with a Claude plan) Add to Claude, then Connect and sign in
Cursor Add to Cursor
VS Code Install in VS Code
Claude Code (API key or Console login) claude mcp add --transport http --scope user ditto https://mcp.ditto.audio, then /mcp -> Authenticate
Claude Code (plugin) /plugin marketplace add ditto-audio/ditto-mcp then /plugin install ditto@ditto-audio
ChatGPT Settings -> Security and login -> Developer mode on, then chatgpt.com/plugins -> + -> https://mcp.ditto.audio
Codex codex mcp add ditto --url https://mcp.ditto.audio then codex mcp login ditto

Headless (CI, servers): skip the sign-in and send an API key from your API keys page as Authorization: Bearer ditto_sk_live_....

Tools

Tool What it does
list_voices Browse the voice catalogue plus your own custom voices
list_languages Every language code and which engines speak it
text_to_speech Synthesize text and get a download URL (MP3 by default; FLAC/WAV and more on request)
create_speech_batch Queue up to 1000 texts at once
get_speech_batch Progress of a batch
get_speech_batch_results Download URLs for a batch's items
cancel_speech_batch Stop a batch; finished items keep their audio
