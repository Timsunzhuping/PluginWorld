BitVisual Agent — MCP Server

Remote MCP server of BIT VISUAL — a digital print shop in São Paulo, Brazil, ready to serve AI agents (A2P: agent-to-print). Browse the catalog, get official quotes in BRL and place PIX-paid print orders directly from any MCP client.

Servidor MCP remoto da BIT VISUAL — gráfica de impressão digital e comunicação visual em São Paulo. Catálogo, cotação oficial por m² e pedidos pagos via PIX, direto do seu agente de IA.

Connection
Endpoint https://bitvisual.com.br/mcp
Transport Streamable HTTP (stateless JSON-RPC 2.0)
Auth None (public)
Docs https://bitvisual.com.br/para-agentes · llms.txt

Claude Code / Claude Desktop

claude mcp add --transport http bitvisual https://bitvisual.com.br/mcp

Tools

Tool Description
catalogo(categoria?) Product catalog with pricing model (per m², fixed, per print run, or quote-only)
cotar(produto, largura_cm, altura_cm, quantidade) Official price quote in BRL — dimensions always in centimeters
prazo(produto, cep?) Production time and delivery/pickup options
validar_arte(produto?) Print-file requirements (formats, DPI, bleed) and how to send artwork
criar_pedido(...) Places a real order and returns a PIX copy-paste payment code (orders ≤ R$ 1,000; above that becomes a human-assisted quote)
status_pedido(numero, email) Order status (requires order number + e-mail)

Example

curl -s https://bitvisual.com.br/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{
       "name":"cotar","arguments":{"produto":"banner-lona",
       "largura_cm":300,"altura_cm":200,"quantidade":1}}}'

Rules for agents

  • Dimensions are always centimeters — never assume the unit, confirm with the customer.
  • "Sob consulta" products (signage, neon, facades, custom acrylic) have no automatic price: route the customer to human service (WhatsApp +55 11 97216-0864).
  • Payment is PIX only; production starts after payment and artwork approval.
