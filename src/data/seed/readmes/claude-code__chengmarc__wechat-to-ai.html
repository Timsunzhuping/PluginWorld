微信.skill

让 AI 在本地读懂你的微信。

安装

需要 Windows, 微信 PC 4.1+, Claude Code。 在 Claude Code 里执行：

/plugin marketplace add chengmarc/wechat-to-ai
/plugin install wechat-to-ai@chengmarc

装好后不需要记任何命令，直接说人话就行。

首次使用

  1. 保持微信登录，然后对 Claude 说「帮我准备微信数据」。
  2. 本插件的所有命令都是 PowerShell，所以第一次运行时 Claude 会请求执行 PowerShell 的权限。 请选择允许；如果选项里有「不再询问 / 始终允许」，选它，之后就不会再被打断。

    全新的目录默认没有这个权限，会在第一条命令就卡住 —— 这不是出错，同意即可继续。 事后想调整，在 Claude Code 里用 /permissions 管理。

  3. Claude 会跑 preflight 自检，并把接下来该做什么逐条告诉你。
  4. 准备数据需要管理员权限，但你不用自己开管理员终端，也不用记任何命令 —— Claude 会替你弹出一个提权窗口，你只需要点一下「是」。
  5. 窗口跑起来后，请在微信里逐个点开聊天（新旧都开）、通讯录、收藏、朋友圈并搜索 —— 微信只在相关内容被打开时才准备对应的数据，浏览得越全，能读到的记录越全。 等窗口里的计数不再增长，在那个窗口里按一次 Ctrl+C，然后告诉 Claude 你按完了。
  6. Claude 接着会（同样弹一次提权窗口）把数据库建好。之后想拿到最新消息，让 Claude 重跑一次建库即可； 日常使用直接提问。

Windows Defender 等杀毒软件会将本程序标记为可疑，需要手动放行。

数据安全

  • 数据不离机：构建数据库、查询、导出全部在本地进程完成，没有任何网络上传。
  • 无遥测：不含任何统计、崩溃上报或更新通道；维护者在技术上无法接触到你的任何数据。
  • 仅限自用：仅用于 在本地 读取 你自己的 微信数据，遵守相关法律法规， 不得用于未经授权的数据访问。
