Skills for Real GTM

This repo is the home of the BlitzAPI MCP server, a hosted remote server that gives agents B2B data: search and enrich companies and people, verified work emails, US phone numbers, job postings, and the live Blitz docs. It also holds the Blitz agent skills.

Agent skills for going to market with Blitz API — lead-finding scripts, outreach, content, analytics, lifecycle automation, and the engineering that powers them.

Blitz MCP server

What it does

Search and enrich B2B companies and people: verified work emails, US phone numbers, job postings. The server exposes one tool per Blitz API endpoint, plus tools to search and read the live Blitz docs, so an agent can look up how an endpoint works and call it in the same session. The plugin installs below ship it preconfigured.
URL https://api.blitz-api.ai/mcp
Transport Streamable HTTP
Auth OAuth (sign in with your Blitz account) — or an x-api-key header
Registry name ai.blitz-api/b2b-data (MCP Registry)

The committed configs (.mcp.json for Claude Code and Grok, mcp.cursor.json for Cursor) use OAuth and contain no secrets. If you prefer an API key, pass it as a header in your own local config and never commit it, for example claude mcp add --transport http blitz-api https://api.blitz-api.ai/mcp --header "x-api-key: YOUR_API_KEY". Full per-agent setup: Connect Your AI (MCP).

API tools draw on the records in your plan's allowance. Search tools bill per result returned (set max_results to control it); lookups and enrichments bill when they succeed. Request bodies and valid filter values come from the server itself, so ask your agent to run docs_search before building a query.

Account and pricing

A Blitz account is required. Your client opens an OAuth sign-in on first use, so there is no API key to copy. Plans and pricing are on the Blitz website.

Quickstart (30-second setup)

  1. Run the skills.sh installer:
npx skills@latest add api-blitz/skills

  1. Pick the skills you want, and which coding agents you want to install them on.

  2. You're ready to go.

Install by agent

The skills.sh installer above works for Claude Code, Codex, Cursor, and other Agent Skills-compatible agents. The options below also add the Blitz MCP server.

VS Code (GitHub Copilot)

Add the MCP server with the VS Code CLI:

code --add-mcp '{"name":"blitz-api","type":"http","url":"https://api.blitz-api.ai/mcp"}'

Or add it to .vscode/mcp.json in your project:

{ "servers": { "blitz-api": { "type": "http", "url": "https://api.blitz-api.ai/mcp" } } }

Start the server and sign in with your Blitz account when VS Code prompts.

Claude Code

Install the plugin (skills + MCP server as one managed install). Inside Claude Code:

/plugin marketplace add api-blitz/skills
/plugin install blitz-api-skills@blitz-api

Or from your shell:

claude plugin marketplace add api-blitz/skills
claude plugin install blitz-api-skills@blitz-api

Then run /mcp, select blitz-api, and sign in with your Blitz account.

Grok

grok plugin install api-blitz/skills --trust

The first Blitz tool call opens OAuth in the browser.

Cursor

Install the skills with the skills.sh installer above, and add the MCP server to mcp.json (Cmd/Ctrl + Shift + P → Open MCP Settings):

{
  "mcpServers": {
    "blitz-api": {
      "url": "https://api.blitz-api.ai/mcp"
    }
  }
}

Claude.ai and ChatGPT

Add https://api.blitz-api.ai/mcp as a custom connector (remote MCP server) and sign in with your Blitz account. In Claude.ai: "+" → Manage Connectors → Add custom Connector.

Layout

Skills live under skills/, grouped into buckets:

  • Blitz — skills that wrap Blitz API directly (Waterfall ICP, People/Company Search, enrichment, integration recipes).
  • GTM — general lead-finding scripts, outreach, content, sales motions, analytics, lifecycle automation, and the engineering that powers them.
  • Productivity — general workflow tools, not GTM-specific.

openai-plugin/ holds the listing metadata, icons, and MCP config for the ChatGPT and Codex plugin. Run scripts/build-openai-plugin.sh to build the ZIP you upload at platform.openai.com/plugins. Its version fields must match .claude-plugin/plugin.json, and the script fails if they don't.

See CLAUDE.md for the governance rules each bucket follows, and CONTEXT.md for the shared language used across these skills.

Reference

Blitz

Skills that wrap Blitz API directly — Waterfall ICP cascades, People Search, Company Search, enrichment, and integration recipes.

  • blitz-gtm-brainstorm — interview a GTM goal into a validated, enum-checked Blitz brief (endpoint choice, ICP filters, enrichment, volume estimate).
  • blitz-create-script — turn a GTM brief into a runnable, install-and-go Blitz SDK script with API-key safety, error handling, and pagination.
  • blitz-reviewer — review a Blitz integration before you run it: MCP installed, SDK & skills current, correct methods/bodies/enums in your code, and per-endpoint RPS/credits.

GTM

General go-to-market work — lead-finding scripts, outreach, content, analytics, lifecycle automation, and the engineering that powers them.

Productivity

General workflow tools, not GTM-specific.

Contributing

When you add a skill:

  1. Put it in the right bucket (blitz/, gtm/, or productivity/).
  2. Add the skill to:
    • this README.md (under the matching section above), and
    • .claude-plugin/plugin.json (the skills array), and
    • the bucket's own README.md.
  3. Link any non-obvious design decisions in docs/adr/.
  4. If you deliberately rejected a feature request, document it in .out-of-scope/.
