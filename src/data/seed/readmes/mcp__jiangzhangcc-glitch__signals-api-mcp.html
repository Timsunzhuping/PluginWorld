Signals API — MCP server

An MCP server that gives Claude / Cursor / any MCP client AI signals data: today's signals, what changed, and ranked AI models & repositories.

No API key needed for the free tier. Single file, Python standard library only — no pip install.

What it gives an agent

Tool What it returns
daily_signals Today's 4 signals — one from each core source (GitHub, Hugging Face, YouTube, Silicon Valley news), each linking to the original
what_changed Deltas since the previous snapshot: new entries, entities no longer seen, rank movers
top_models Hugging Face models with rank, rank movement and momentum, plus a ready-to-cite sentence
top_repos GitHub repositories, same shape
archive_days Which daily editions exist (for citing a specific date)

Every ranked row carries a citation string, so an agent can cite the number instead of inventing one. Entities whose number cannot be derived are published as unranked with the reason — we would rather return "not ranked" than a made-up value.

Use it without installing anything (hosted endpoint)

There is also a hosted MCP endpoint, so no download and no local Python is needed — point any MCP client that speaks streamable HTTP at:

https://data.jiangzhang.ca/signals4/mcp

It is published in the official MCP Registry as ca.jiangzhang.api/signals-api-mcp and serves the same five tools as the single-file version. A quick check with curl:

curl -s -X POST https://data.jiangzhang.ca/signals4/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -A 'my-agent/1.0' \
  --data '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

(The User-Agent header matters here too — see the CDN note further down.)

Install

  1. Download mcp_server.py anywhere (e.g. ~/mcp/signals/mcp_server.py).
  2. Add it to your MCP client config:
{
  "mcpServers": {
    "signals": {
      "command": "python3",
      "args": ["/absolute/path/to/mcp_server.py"]
    }
  }
}

Claude Desktop: ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) or %APPDATA%\Claude\claude_desktop_config.json (Windows). Restart the client and the five tools appear.

Requires Python 3.9+. No dependencies, no key, no signup.

Try it without an MCP client

echo '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"daily_signals","arguments":{}}}' \
  | python3 mcp_server.py

A trap worth knowing (we hit it ourselves)

The CDN in front of the API rejects the bare Python-urllib/… User-Agent and empty User-Agents with HTTP 403. requests, httpx, aiohttp, Go, node-fetch, axios, okhttp and curl are all fine — but if you write a plain-stdlib example and forget the header, you will see a 403 that looks like a broken API. This server always sends one. If you call the endpoints directly, set a User-Agent:

curl -H 'User-Agent: my-app/1.0' https://data.jiangzhang.ca/signals4/api/today.json

Data sources and license

Signals are collected from public APIs and public feeds (GitHub trending, Hugging Face, YouTube channels, arXiv, LMSYS Arena, silicon-valley news, hardware/chips). Each item links to its original source; we do not rewrite it. Derived rankings and momentum are recomputed from our own daily snapshots by an automated audit that also reconciles the site pages with the JSON endpoints.

Development

The server is a single file, stdio JSON-RPC, no framework. Read a request line, write a response line. initialize, tools/list, tools/call, ping are implemented; unknown methods return JSON-RPC -32601 rather than failing silently.
