Iran MCP servers: awesome-iran-mcp

Give your AI agent the Iranian web.
20 unofficial, open-source Persian-web MCP servers for Digikala, Divar, Snappfood, Jabama, MrBilit, Paziresh24, Taaghche and more, plus official ones from ExirYab, Pasavard and SwapWallet.
Search, compare prices in Toman, find free slots and today's deals from Claude, Cursor, GitHub Copilot in VS Code or any MCP client.
Install them as Claude Code plugins with skills, or as Agent Skills for Codex, Cursor, Antigravity and Grok Build.

Why

Iranian websites are not built for AI agents. Most have no public API, prices come in Rial on one page and Toman on the next, and every site hides its best deals behind a different menu. Each package server here maps one site's real (undocumented) API, tests it, and exposes it as clean MCP tools with prices in Toman. exiryab-mcp, pasavard-mcp and swapwallet-mcp are the sites' own servers, built on their documented APIs.

Put a few of them together and one sentence does a day of tab-hopping (illustrative example):

You: I'm flying Tehran to Kish next Thursday for 3 nights. Cheapest flight, a villa under 4 million Toman a night, and a dermatologist on the island with a free slot.

Agent: calls mrbilit for flights → jabama and otaghak for stays → paziresh24 for doctors

Pick Price (Toman)

Stay 2-bedroom villa near the beach, 4.8 stars 3,650,000 / night
Doctor Dermatologist, Saturday 10:30, in-person 450,000

Quick start

Every server is a small Python package on PyPI, run with uvx, except pasavard-mcp and swapwallet-mcp, which their sites host: you add them by URL, and sign in to SwapWallet once with OAuth. The site servers need no account and no API key. payping-mcp and bale-mcp work on your own account with your token, and swapwallet-mcp with your SwapWallet sign-in.

Claude Code plugins (server + skill, pick what you want): add the marketplace once, then choose servers in the /plugin Discover tab, or install by name.

claude plugin marketplace add sepehr071/awesome-iran-mcp
claude plugin install digikala@iran-mcp            # one server
claude plugin install iran-travel@iran-mcp         # a bundle: food, shopping, beauty, travel, health, books
claude plugin install iran-all@iran-mcp            # every read-only site server

claude plugin install <name> --marketplace sepehr071/awesome-iran-mcp does both steps in one command. payping, bale and swapwallet act on your own account, so no bundle includes them; install them by name. SwapWallet also publishes this server as its own plugin (swapwallet@swapwallet, from SwapWallet/swapwallet-mcp), with the same rules. Install one of the two: with both you get the server twice.

Skills for other agents (Codex, Cursor, Gemini CLI, ...): pick the skills you want, then add each server with the config below.

npx skills add sepehr071/awesome-iran-mcp

Grok Build reads the same marketplace: grok plugin marketplace add sepehr071/awesome-iran-mcp, then install servers one by one (Grok doesn't install a bundle's members). Which agent supports what: PLUGINS.md.

One server (Claude Code, without the plugin):

claude mcp add digikala -- uvx digikala-mcp
claude mcp add --transport http swapwallet https://swapwallet.app/mcp   # hosted; then sign in from /mcp
claude mcp add --transport http pasavard https://pasavard.ir/api/mcp      # hosted, no sign-in

Any MCP client (Claude Desktop, Cursor, Windsurf, VS Code, ...):

{
  "mcpServers": {
    "digikala": { "command": "uvx", "args": ["digikala-mcp"] },
    "jabama":   { "command": "uvx", "args": ["jabama-mcp"] }
  }
}

swapwallet-mcp is added by URL, and each client takes a URL in its own shape (Windsurf uses serverUrl, Claude Desktop takes it under Settings → Connectors): see its setup for each client.

All 23 at once: clone this repo and open it in Claude Code. The .mcp.json at the root registers every server; approve the ones you want.

git clone https://github.com/sepehr071/awesome-iran-mcp
cd awesome-iran-mcp && claude

[!TIP] 359 tools is a lot of context. Enable the servers for the task at hand rather than all of them.

Shared conventions

  • Prices are always Toman, even where the site's API returns Rial.
  • Site servers are read-only. Shop, travel, health and book servers never log in, fill a basket, book or pay. payping-mcp and bale-mcp can write, but only to your own account, with your token, on your machine. swapwallet-mcp works on your own SwapWallet account after you sign in, and a swap, transfer or withdrawal it asks for runs only after you approve it in Telegram.
  • Images: product, stay, hotel and doctor results carry an image URL where the site has one.
  • Proxy: every package server reads an optional <NAME>_MCP_PROXY env var (e.g. DIGIKALA_MCP_PROXY) for sites that block your IP. System proxy settings are ignored. See servers.json for exact names.
  • Same layout for every package server: src/<pkg>/http.py, registry.py, server.py, offline tests on recorded fixtures, -m live tests against the real site, published to PyPI and the MCP Registry.

Working from source

Each server lives in its own repo and is pinned here as a git submodule under servers/. A hosted server's repo holds its server.json and client configs, not its code; catalog.py reads its tools from the server card it publishes.

git clone --recurse-submodules https://github.com/sepehr071/awesome-iran-mcp
cd awesome-iran-mcp/servers/digikala-mcp
uv sync && uv run pytest -q          # offline tests
uv run pytest -m live -q             # against the real site

Pull every server to its latest main and rebuild the catalog:

git submodule update --init --remote
python scripts/catalog.py            # rewrites servers.json, TOOLS.md, .mcp.json, plugins/, .claude-plugin/
python scripts/banner.py             # redraws both banners with the new counts
claude plugin validate .             # checks the marketplace and every plugin

A nightly GitHub Action does all of this and commits the result. The full release flow is in PLUGINS.md.

Bugs and feature requests for a server go to that server's own repo.

FAQ

Are these official?

All but three are unofficial and not affiliated with the sites. They call the same endpoints the sites' own web apps use. Those APIs are undocumented and can change; open an issue on the server's repo when one breaks. swapwallet-mcp is SwapWallet's own server, documented at swapwallet.app/docs/mcp. exiryab-mcp is ExirYab's own server, on the public API listed in exiryab.com/llms.txt. pasavard-mcp is Pasavard's own hosted server; its store links are affiliate links, and every result says so.

A site times out or returns 403 from outside Iran.

Some sites block foreign IPs. Set that server's proxy variable, e.g. DIGIKALA_MCP_PROXY=http://127.0.0.1:8080, to a proxy with an Iranian exit.

Can my agent order or pay for me?

Not on the sites: the site servers are read-only on purpose. Your agent finds and compares; you buy. The exception is your own SwapWallet account: with swapwallet-mcp your agent can ask for a swap, transfer or withdrawal, and nothing moves until you approve it in Telegram.

Do I need Python?

You need uv. uvx downloads the right Python and the package on first run. pasavard-mcp and swapwallet-mcp run on their sites' servers and need nothing installed.

How do I get updates?

Plugins pin each package server to a release, so a plugin update is a server update. pasavard-mcp and swapwallet-mcp are hosted: they change whenever their sites deploy them, and a plugin update only brings a new skill. Turn on auto-update once in /plugin → Marketplaces → iran-mcp, or run claude plugin update <name>@iran-mcp. A plain uvx digikala-mcp config keeps running its cached copy; run uvx digikala-mcp@latest --help once and restart your client to upgrade it.

If this saves you some tab-hopping, a star on the repo helps other people find it.
