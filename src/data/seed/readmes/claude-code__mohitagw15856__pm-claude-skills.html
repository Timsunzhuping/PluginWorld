🧠 PM Skills: Professional Agent Skills for Claude, ChatGPT, Gemini, Cursor, Codex & Hermes

Your landlord kept your deposit. You got laid off on a Tuesday. Your boss wants the PRD by Friday. Generic AI is a very confident intern. PM Skills is the senior colleague's notes: 1285 of them, one markdown file each. (PM stands for Professional. Yes, we get asked.)

▶ Playground · ⚡ Install · 📚 All skills · 🖼 Showcase · 🌳 Tech tree · 🇨🇳 简体中文 · 繁體中文 · 한국어 · 🆕 Changelog

PM Skills is an open-source library of 1285 Agent Skills — plain-markdown SKILL.md files that teach an AI assistant to do one professional task to a senior professional's standard, from writing a PRD to decoding a lease or running a blameless postmortem. Each skill bundles the framework, an output template, quality checks, and anti-patterns. It is MIT-licensed and works with Claude, ChatGPT, Gemini, Cursor, and Codex.

⚡ Install in 30 seconds

npx pm-claude-skills add                                            # any tool: Cursor, Codex, Windsurf, Cline, Zed…
# In Claude Code:  /plugin → search pm-skills   (official Anthropic directory)
npx --registry=https://registry.npmmirror.com pm-claude-skills add  # 中国大陆镜像

Then just say what you need: "Decode this job ad and tell me where I am weak." Nothing here can break your setup: a skill is a markdown file your AI reads; installing copies text files, uninstalling deletes them. Read one first. Per-tool instructions: docs/installation.md · ChatGPT and Gemini: copy from exports/ · MCP: claude mcp add pm-skills -- npx -y -p pm-claude-skills pm-claude-skills-mcp

✅ Trust and quality

An honest summary of what is checked, measured and still unreviewed, as of 2026-10-06:

  • Checked on every change, in CI: structure (SkillCheck, all 1285 skills at the L3 gate), a security audit, a near-duplicate check, a count-drift check, translation parity across 108 locales, and a prompt-injection suite. A change that fails any of them does not merge.
  • Eval cases: 389 of the 1285 skills carry eval cases (evals/cases.json); coverage grows with each release.
  • Measured scores: 28 skills have blind-judged scores on the leaderboard (average 4.8/5); the benchmark report publishes the negative findings too. Everything unscored is unscored, not assumed good.
  • Human review: of the 155 skills rated high-stakes in risk tiers, 0 have been reviewed by a licensed professional so far. The expert-review programme and its ranked queue exist precisely for this; if you hold a relevant credential, reviewing one skill is the single most valuable contribution available.
  • Honesty rules baked in: decoders end with a not-advice line (the severity scale), calculators name what they do not model, simulators debrief out of character. PM Skills is not a substitute for a professional.

Privacy: off by default; skills, the CLI and exports send nothing (docs/TELEMETRY.md · SECURITY.md). Verify a release: npx pm-claude-skills verify --release (signed SBOM, Sigstore provenance).
