# PluginWorld — agent guide

Shared instructions for every coding agent on this repo (Codex reads this file
directly; Claude Code reads it through `CLAUDE.md`). Keep project rules here only.

PluginWorld (https://pluginworld.ai) is a cross-ecosystem AI plugin marketplace:
one search box for DeepSeek Harness (dsh) plugins, Claude Code plugins, MCP
servers and Agent Skills, with a unified quality score and a pre-index security
grade. Upstream spec: `../plugin-marketplace-开发方案.md` (not in this repo).

## Hard rules

- Tech stack is fixed: Next.js App Router + TypeScript + Tailwind v4 + Drizzle + Postgres. No new dependencies without a stated reason in the PR.
- Column names in `src/lib/db/schema.ts` are snake_case and must not drift.
- Before every commit run `npm run typecheck && npm run lint && npm test`. All must pass.
- `src/lib/scoring.ts` and `src/lib/security.ts` stay pure functions; every behaviour change ships with a test.
- Each ecosystem validator in `src/lib/validators/` keeps ≥3 passing and ≥3 failing test cases.
- All user-facing site copy is English.
- **Never hand-edit `src/data/seed/`.** It is generated by `npm run sync` and rewritten daily by the bot.
- Never commit secrets. Third-party README text passes through `redactSecrets()` (`scripts/sync/lib.ts`); add new token patterns there.
- Index public metadata only and link back to the source. Do not mirror proprietary code or scrape sources that forbid it (decision 2026-10-18: no Tencent SkillHub/WorkBuddy ingestion — no public API, no partnership).

## Git workflow (two agents + a bot share `main`)

- Canonical repo: `ApollaAI/PluginWorld`. `Timsunzhuping/PluginWorld` is a mirror; its scheduled scan is disabled.
- `pluginworld-bot` pushes a snapshot commit to `main` every day after the 02:00 UTC scan. Always fetch and rebase before you start.
- Work on a feature branch and open a PR into `ApollaAI/PluginWorld:main`. Never force-push `main`.
- Keep PRs to one concern. In the description, state what changed, how you verified it, and what is still unverified.

## Map

| Area | Where |
|---|---|
| Pages | `src/app/` — `/`, `/browse`, `/plugins/[ecosystem]/[owner]/[name]`, `/submit`, `/docs/api`, `/admin/sync` |
| Public API (read-only, CORS, 60 req/min) | `src/app/api/v1/` — `plugins`, `plugins/{slug}`, `stats`, `sync-status`, `events` |
| Data layer (dual mode) | `src/lib/data.ts` — no `DATABASE_URL` → reads the seed snapshot; with it → Drizzle + Postgres FTS. Both paths must return the same shapes. |
| Scoring / security grade | `src/lib/scoring.ts` (0–100, five weighted dimensions) · `src/lib/security.ts` (A+…D, D is quarantined) |
| Ingestion pipeline | `scripts/sync/run-all.ts` orchestrates GitHub topics, official MCP Registry, npm, Glama (needs `GLAMA_API_KEY`) and skills.sh top 1000 |
| CI | `.github/workflows/sync.yml` (daily scan) → `deploy.yml` (build in CI, ship over restricted SSH, health check, rollback) |
| Deploy ops | `deploy/AUTOMATION.md`, `deploy/receive-release.sh`, `deploy/setup-server.sh` |

## Brand system (V1.0)

- 60% Ink `#16161A` / 30% Paper `#F7F6F3` + White / 5% Volt `#C6FF00`. Volt only for CTAs, live states, key data and hover; text on Volt is always Ink.
- Fonts: Outfit (headings/UI), IBM Plex Mono (code, versions, data, labels), Noto Sans SC fallback for third-party CJK content.
- Radius 8/12px, 1px `#E4E2DC` borders, no shadows.
- Voice: restrained and precise; short sentences, verbs first; "plug in", not "download and install"; numbers in mono.
