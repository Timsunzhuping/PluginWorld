# PluginWorld — Development Rules

The cross-ecosystem AI plugin marketplace (dsh / Claude Code / MCP). Upstream spec:
`../plugin-marketplace-开发方案.md`; brand system: `../PluginWorld 视觉体系.html`.

## Hard rules

- Stick to spec §3 tech choices: Next.js App Router + TS + Tailwind + Drizzle + Postgres. No out-of-spec dependencies.
- The data model follows spec §4; column names in `src/lib/db/schema.ts` must not drift (snake_case columns).
- Run `npm run typecheck && npm run lint && npm test` after every task before moving on.
- Scoring logic (`src/lib/scoring.ts`) must stay pure functions; every change needs a matching test.
- Each of the three validators keeps ≥3 passing / ≥3 failing test cases.
- All user-facing site content is English.

## Brand system (V1.0)

- 60% Ink `#16161A` / 30% Paper `#F7F6F3` + White / 5% Volt `#C6FF00`
- Volt is reserved for CTAs, live states, key data and hover; text on Volt must be Ink; never large body backgrounds
- Fonts: Outfit (headings/UI) + IBM Plex Mono (code/versions/data/labels) + Noto Sans SC fallback (third-party README content)
- Radius 8/12px, 1px `#E4E2DC` borders, **no shadows**
- Voice: restrained, precise, electric; short sentences, verbs first; say "plug in", not "download and install"; numbers in mono

## Dual-mode data layer

`lib/data.ts`: without `DATABASE_URL` it reads the `src/data/seed/` snapshot (never
hand-edit; generated by `npm run sync`); with it, Drizzle + Postgres FTS. Both sides
must behave identically.
